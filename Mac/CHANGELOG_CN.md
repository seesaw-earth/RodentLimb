# RodentLimb for Mac 1.4.2 — 更新说明

## 修复：窗口布局死循环导致的闪退（“Update Constraints in Window passes”）
日志中的 `NSGenericException: The window has been marked as needing another Update Constraints in Window pass, but it has already had more Update Constraints in Window passes than there are views in the window` 表示：窗口每次重新布局时，内容又报告了新的（或无法满足的）最小尺寸，AppKit 反复重排直到放弃并结束 App。排查后修复了以下原因：
- **页面的最小尺寸不再传给窗口**：以前主窗口只设了最小值，页面里任何内容（自动换行的长提示、一排按钮、左右分栏）的最小尺寸都会变成窗口的最小尺寸；文字在宽度为 0 时被要求“完整显示”，高度可达数千点，窗口无法满足。现在窗口最小尺寸固定为 860 × 560，每个页面、推入的页面、侧栏和检查器都只占用分配给它的空间，放不下时在页面内滚动。
- **提示条、等待识别的状态文字**：不再强制按完整高度测量；等待识别的说明固定 3 行高度，不随每次进度更新改变页面高度。
- **自适应布局**：两栏/换行布局在被询问最小尺寸时给出真实的小尺寸，而不是整行宽度或逐字换行的高度。
- **高度受限的区域**（处理队列中正在识别的卡片等）：不再在“普通版 / 滚动版”之间来回切换（进度每秒更新数次时会反复重建），改为测量内容高度后固定显示在一个滚动区域内。
- **检查器**：只有最上层页面能更改“显示检查器”，被覆盖或恢复的页面不会把它关掉再打开；同一页面不会被重复推入导航栈（以前 A → 视频 → A 会出现两个相同页面）。
- 窗口宽度变化只在停止调整后处理一次，并且不再在每一帧刷新整个主窗口。

## 修复：识别或回放时卡顿
- 进度、剩余时间、队列位置不再每次都把整个资料库排序（每秒调用数次，资料库大时占满主线程）；改为直接计数。
- 侧栏“处理队列”的进度改为整数百分比文字；进度环不再做动画（每个动画每秒重绘 60–120 次，同时识别多个视频时主线程很忙）。
- 视频页的 QC 播放器：播放时只有“上一个 / 下一个丢失片段”按钮跟随播放位置，不再每秒 10 次重建整张卡片和最多 100 项的菜单；画面上的状态标签不再每帧重建。
- 回放页切换上下 / 左右排列时，不再在每一帧刷新事件列表。
- 关闭页面时立即释放视频：取消未完成的跳转、关闭解码器和文件。快速打开、关闭页面时，不会再留下多个半打开的播放器（日志中的 `FigFilePlayer err=-12860`）。
- 切回 App 时检查视频文件是否可用，一次只做一次，不会在慢速磁盘上叠加。

## 上架准备
- 工程新增最后一个构建阶段 **Remove Extended Attributes**：签名前移除 App 内所有文件的扩展属性（含 `com.apple.quarantine`），避免 Mac 版上传被拒（ITMS-91109）；清不掉时构建报错停下。iPhone 工程同样添加。
- 新增 `tools/app_store_preflight.sh`（iPhone 工程为 `Tools/app_store_preflight.sh`）：归档前清理工程（quarantine、.DS_Store），检查版本号、出口合规、类别、隐私清单、沙盒；归档后检查 .xcarchive / .app / .pkg（无 quarantine、签名、权限、版本、模型与隐私清单在 App 内）。
- 版本 1.4.2（build 8），Mac 与 iPhone 一致；Debug 与 Release 一致。
- iPhone：补充“存储视频到照片”的用途说明（NSPhotoLibraryAddUsageDescription，中英文）。分享导出的骨架视频时选“存储视频”，以前会因缺少说明被系统终止。
- 上架清单（RELEASE_CHECKLIST_CN.md › C）更新：Xcode 26 要求、上传前后的检查步骤、审核附件与可直接粘贴的审核备注。

## 关于日志中的其他信息
`cannot open file … DetachedSignatures`、`task name port`、`ViewBridge … Code=18`、`AddInstanceForFactory`、`audioanalyticsd` 沙盒提示、`HALC … overload` 均为 macOS 系统组件的常见输出，与本次闪退无关；`VRP err=-12852` / `FigFilePlayer -12860 / -12780` 来自视频播放器被关闭时仍在加载，本版已在关闭时主动释放。

# RodentLimb for Mac 1.4.1 — 更新说明

## 布局：适应屏幕，按钮始终点得到
- 主窗口最小尺寸由 1080 × 680 降到 860 × 560，默认大小按当前屏幕计算。以前在 13 英寸屏幕（尤其“更大字体”显示设置）上，窗口底部可能超出屏幕。
- 弹出窗口不再超出屏幕：macOS 的弹出窗口从标题栏下方展开、不能拖动，以前固定 720 点高的导出窗口、680 点的添加视频窗口等在小屏幕或窗口靠下时，底部按钮会落到屏幕外。现在每个弹出窗口都按可用空间限制尺寸，内容区滚动，按钮固定在底部。
- 窄窗口自动改为上下排列：任务页（标题与“添加视频 / 导出”）、视频页（右侧决定栏移到下方）、会话复核页（事件列表移到视频下方）、处理队列（控制按钮移到状态下方）。计数、标签、图例自动换行，不再被截断或挤出窗口。
- 处理队列：正在识别的视频卡片和失败列表最多占页面高度的一部分，超出时在内部滚动，等待队列和它的按钮始终可见。
- 窗口较窄时自动隐藏检查器，拉宽后恢复。
- 视图切换从工具栏移到页面内（Apple 建议工具栏只放操作）；工具栏的“导出”移到各页面（⌘E 不变），“移到任务…”移到检查器和右键菜单，工具栏更简洁。
- 侧栏：“新建任务…”改为整行按钮，不再是分组标题里的小字；底部的语言和“显示”改为标准小按钮，更容易点中。
- 任务备注在页头最多显示 3 行，避免挤占会话列表。

# RodentLimb for Mac 1.4.0 — 更新说明

## 先选任务，再处理视频（参照 RodentFlow build 11）
- 侧栏改为**任务 → 组别**：每个任务显示名称、范式、会话数和待复核数，展开即为各组（带会话数），选中某组时任务页只显示该组。下方“列表”为处理队列、待复核、失败、全部视频、未归入任务。原来的概览、研究页和按任务列出的分析页合并进任务页。
- **新建任务**（⇧⌘N）：先选范式（按用途分组，每项一句说明），再填名称、组别、时间点、备注、是否盲法。没有任务时首页只有“新建任务…”一个按钮。
- **添加视频**只在任务里进行（⌘O、任务页按钮、或拖入窗口），范式固定为该任务的范式。表格新增**组别**列：文件名或文件夹名中含组名时自动选中；任务里已有的动物保持原组别；可多选批量设组。添加后每段视频立即成为任务里的一个会话，不必等识别和纳入。
- **任务页**：顶部是名称、范式、各状态数量（会话 / 识别中 / 待复核 / 失败 / 已排除 / 已分析）和“添加视频…”“导出…”；下方三个标签——会话（按组别、动物、时间点、试次排列，状态列实时显示“识别中 45%”“待复核”“需要标定”等）、结果（组间比较、完整性、排除记录）、设计（组别与动物、随机分组、盲法、QC 标准、方法学文字、删除任务）。
- 会话右键：打开、打开视频与 QC、纳入、排除、退回待复核、重新分析、复制参数到所选、导出所选、移到其他任务、移出任务、删除视频。移动、移出和删除任务都可在底部提示条“撤销”，并精确复原（原会话从“最近删除”恢复，新建的会话清除）。
- 一段视频只属于一个任务所在的研究：移到另一个研究的任务时，原会话移到“最近删除”，不会留下副本；动物的组别随视频带过去。移出任务的视频以文字保留组别。盲法中的任务不能移出视频（避免泄露分组）。
- 添加视频时，同一只新动物被设为两个组会提示并阻止添加；没有动物编号的视频不能选组别。
- 导出新增“任务”范围（⌘E 在任务页默认导出当前任务，选中会话时导出所选）。
- 旧资料库照常打开：多范式研究显示为多个任务（“研究名 · 范式”），无范式研究在“未归入任务”中选一个范式即成为任务；文件格式不变，仍可与 iPhone 交换。

## 可视化
- 组间比较默认改为散点图：每只动物一个点（轻微错开），横线为组均值，误差线为 ± 标准误；每组下方标注 n（动物数）。也可切换为柱状图。
- 各组使用色盲友好的 Okabe–Ito 配色，时间进程图同色；网格线减弱，坐标轴数字等宽。

## 去掉多余的图标
- 按钮、菜单、侧栏、卡片标题、提示条、空状态、状态标签和任务徽标都改为纯文字；状态用彩色文字或小圆点表示，范式用文字缩写（如 GAIT、CYL）。只保留播放控制、逐帧按钮和系统自带的展开箭头等功能性符号。完整性表格用实心点 / 空心环区分状态，不只靠颜色。

## 姿态模型
- 移除 38 MB 的 **CylinderMousePoseV2**。现在提供两个模型：CylinderPose7_FP16_640（默认，可见光；与 V2 为同一网络的半精度版本）和 PalmReaderPose8（近红外暗箱）。
- 旧视频不受影响：没有记录模型的视频仍标为 CylinderMousePoseV2，导出照常写明；重新识别时改用 FP16。设置中保存过 V2 为默认的，自动改为 FP16。

## 数据安全
- 删除任务时可选择保留视频（移到“未归入任务”）或一并删除，两者都进入“最近删除”，可恢复；移出任务后可立即撤销。
- 新建任务、添加视频、移动视频后立即写盘。

## 验证
- 核心测试新增“任务”35 项（共 150 项），全部通过；导出检查通过。
- 视频表格、添加视频、队列、任务页、新建任务、侧栏、主窗口、研究设计等界面文件用替身框架类型检查，0 错误。

# RodentLimb for Mac 1.3.5 — 更新说明

## 姿态模型顺序与默认
- 选项顺序改为：**① CylinderPose7_FP16_640（默认）→ ② PalmReaderPose8（近红外暗箱）→ ③ CylinderMousePoseV2（全精度，与 iPhone 相同）**。导入表格、重新识别菜单、设置和概览都按此顺序显示。

## 视频解码检查
- 导入时询问 macOS 能否解码该视频，并试解一帧。没有解码器的编码（如 M1/M2 Mac 上的 AV1；控制台里的 `VT-DS err=-12906`）会在导入表格中标为“无法读取”，并说明如何转换为 H.264 MP4（含 ffmpeg 命令）；试解失败会给出警告。
- 识别时遇到无法解码的视频会立即失败并写明原因，不再白白重试 3 次。编码名称新增 AV1、VP8、VP9。

# RodentLimb for Mac 1.3.1 — 更新说明

## 修复（你遇到的问题）
- **打开“待复核”、全部视频或研究页时卡住后闪退**：日志里的 `No Observable object of type AppModel found` 来自 macOS 的表格单元格（`TableColumn`）有时拿不到窗口的环境对象。视频表格里的缩略图和状态单元格以前从环境读取 App 状态，现在改为直接传入；所有弹出窗口、浮层和检查器也都显式传入 App 状态，同类崩溃不会再出现。

- 日志里的 `FigFilePlayer err=-12860`、`audioanalyticsd`、`ViewBridge`、`DetachedSignatures` 是 AVFoundation/macOS 的系统信息，不影响结果，可以忽略。

## 简体中文与应用内切换语言
- 菜单栏“RodentLimb › Language · 语言”、侧栏底部地球图标、欢迎页、设置都可切换：跟随系统 / English / 简体中文，立即生效，不丢当前页面。
- macOS 系统菜单和文件面板也会跟随（App 内带 en / zh-Hans 本地化），需要重启时会询问，重启前自动保存并停止批处理，重启后继续。

## 数据安全
- 最近删除：删除的视频、分析、研究保留 30 天，可恢复；删除后提示条可“撤销”。
- 自动备份研究、视频信息、纳入决定和分析参数（每日 + 删除/批量修改前），可在设置中恢复，恢复前先备份当前状态。
- 纳入/排除决定立即写盘；App 进入后台、Mac 睡眠时立即保存；研究页文本框在关闭时也会保存。
- 同一资料库被两台 Mac 同时打开时提醒。

## 更流畅
- 视频、分析、研究的查找改为索引（O(1)），大资料库的表格、批量纳入和“应用到…”更快。

## 参数预设（对照已发表研究）
- 分析检查器顶部新增“实验方案”预设：悬尾（后 4 分钟 / 完整 6 分钟）、福尔马林（Mogil 1999 / Hunskaar 1987 / Nian 2014）、步态（JAX Sheppard 2022）、圆筒（前 20 次 / 5 分钟）、瘙痒（30 分钟 / 60 分钟）、理毛（10 分钟 / Kalueff 5 分钟 / 适应后 10–20 分钟）、癫痫（PTZ 30 分钟 / 海人酸 2 小时）、关键点置信度（0.3 / 0.6 + 去跳点）。默认值不变；详见 README 第 6 节的对照表和来源。

# RodentLimb for Mac 1.3 — 更新说明

第一个 Mac 版本。分析部分与 iPhone 1.3 完全相同（`Shared/` 逐字节一致）；以下是 Mac 版新增和不同的地方。

## 批量处理
- 拖入文件或文件夹即可导入，文件夹会递归查找视频。导入前先读出视频信息，提示不可读的格式，并检测重复文件。
- 按文件名或文件夹名自动识别动物编号、时间点和试次，规则可以自定义（分隔符 + 第几段）。多个视频可以一起编辑。
- 处理队列：可同时处理 1–3 个视频，显示实时画面、进度、帧率和剩余时间，以及整个队列的预计完成时间；可以暂停、继续、调整顺序和取消。Dock 图标显示进度；完成后发系统通知；可防止系统休眠。
- 逐帧检查点：暂停、退出、崩溃或断电后，从最后保存的帧继续，续跑结果与一次跑完完全相同。
- 自动重试；同一视频连续两次意外退出后自动搁置；视频离线时跳过并等待；磁盘空间不足时暂停；所有操作写入活动日志。
- 后台同时计算多个分析。

## 数据组织
- 资料库目录结构与 iPhone 版相同，可以在 Mac 和 iPhone 之间拷贝，可放在任意位置（外置硬盘、项目文件夹）。
- 视频默认原地引用，不复制；移动后可以重新定位，用指纹核对是否为同一个文件。
- 原生表格：可排序、搜索、多选、右键菜单，右侧检查器显示所选内容。支持键盘快速复核。

## 导出
- 一次导出所选内容、一个任务、一个研究或整个资料库，每个任务一个文件夹，附数据字典（README）和清单（manifest）。
- **行为片段表**：所有视频的事件或 bout 汇总在一张长格式表中，含自动标签、复核后标签和人工修改标记。另有行为谱、时间进程（长格式）、悬尾、圆筒、步态明细，以及 QC 与纳入/排除表、方法学文字。
- 可与其他工具互通：BORIS 事件表、DeepEthogram/daart 逐帧标签、DeepLabCut 格式关键点（可用于 SimBA、Keypoint-MoSeq）。

## 与 iPhone 版的差异
- 不提供“渲染骨架视频”选项；Mac 上不录制视频。
- 姿态推理路径与 iPhone 相同（Vision、.scaleFit、同一解码器）。Intel Mac 上半精度输出改为逐位转换，数值不变。
