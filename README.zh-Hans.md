# RodentLimb

**使用手册（中文 / English）：https://seesaw-earth.github.io/RodentLimb/zh/** · [隐私政策](https://seesaw-earth.github.io/RodentLimb/zh/privacy.html) · [支持](https://seesaw-earth.github.io/RodentLimb/zh/support.html) · 许可证：GNU AGPL-3.0

基于 **CylinderMousePoseV2** 的端侧肢体姿态分析 App，支持**悬尾实验**、**圆筒实验**和**步态分析**。模型有 7 个关键点：左右前爪、左右后爪、尾根、鼻尖、嘴。与 RodentPose、RodentFlow 同系列，沿用同一种蓝色主色、卡片布局和 Okabe–Ito 数据配色。爪的配色与 App 图标一致。

## 安装（Mac）

```bash
cd ~/Downloads/RodentLimb
python3 Tools/install_model.py --v2 ~/Downloads/CylinderMousePoseV2.mlpackage.zip
open RodentLimb.xcodeproj
```

`--v2` 也可以直接指向 A/B 工程里已装好的模型：
`~/Downloads/CylinderPose_DualModel_AB/CylinderPose/CylinderPose/Models/CylinderMousePoseV2.mlpackage`。
工程使用同步文件夹（Xcode 16+），模型和所有源文件会自动加入，不要再手动拖入模型。选好 Signing Team 后，在 iOS 17 以上的 iPhone 上运行。


## 1.1.2 更新（流畅度）

- **回放拖动**：画面和关键点现在同步移动。跳转采用 Apple 推荐的“追赶式跳转”（QA1820）：只处理最新的目标位置，关键点按屏幕上实际显示的那一帧来画。也可以在视频上左右滑动逐帧移动（每 6pt 一帧）；逐帧按钮有轻触觉反馈。
- **不再整页重绘**：识别进度（降到每秒最多 4 次）和播放时钟只刷新显示它们的小组件，不再连带刷新整页的图表和表单。
- **后台写盘**：保存记录时合并多次写入，并在后台线程完成；拖动参数滑块时只重绘参数表单，停顿片刻后才重新分析；导出大体积的逐帧姿态 CSV 也改在后台生成。
- **文字输入**：按回车跳到下一个输入框；数字键盘有“完成”键；拖动页面即可收起键盘；输入时底部按钮自动隐藏。

- **步态方法学 v2**（参考 Sheppard 等 2022；Bellardita & Kiehn 2015；Batka 等 2014）：
  - 只保留直线行走时的步幅（默认角速度 ≤ 30 °/s），并去掉每段行走的首尾步幅（加减速期）。
  - **速度匹配值**：按每只动物自身“步幅指标—速度”的拟合线，读取共同参考速度（2 体长/秒）下的数值。动物从未在该速度附近行走时留空，不做外推。
  - 新增步幅变异系数（CV）、步长、以体长为单位的步幅。
  - 新增每个步幅的步态模式分类（慢走 / 小跑 / 跑步 / 跳跃）。
  - 新增鼻尖和尾根的侧向摆动（幅度与相位），作为全身协调指标。
  - 已在模拟小鼠上验证（`Tools/validation/test3.py`）：
    - 步长 25.6 像素（真值 25）
    - 鼻尖摆动 0.129 体长（真值 0.133）
    - 速度匹配步幅 50.2 像素（真值 50.0）
    - 转向步幅被正确排除，小跑被正确识别

## 使用流程

1. **新建分析**：选择范式，再选择一个或多个视频（照片或文件）。动物编号默认取文件名。
2. **姿态识别**：每个视频只跑一次，在后台队列中逐个处理，期间屏幕保持常亮。离开 App 会暂停，回来后自动继续。
3. **标定**：只有部分范式需要。圆筒实验要标出圆筒边缘（仰视）或地面线（侧视）；步态可选加厘米标尺。可以用“自动”根据追踪结果给出初始位置，放大镜帮助精确放置。相机固定时，一次标定可用于所有视频。
4. **结果**：拖动参数滑块后立即重算，不会重新运行模型。回放时实时叠加关键点，支持逐帧步进和 0.25–4 倍速播放。
5. **导出**：始终为英文，包括汇总、事件或步幅表、逐帧姿态 CSV，以及包含参数值和参考文献的方法描述。“数据”页可按范式导出宽表（每只动物一行），并可快速做组间比较。

## 指标

| 范式 | 指标 |
|---|---|
| 悬尾 | 不动时间及比例（默认统计第 2–6 分钟）、潜伏期、不动次数、平均与最长不动时长、逐分钟曲线、爬尾比例、后肢抱握估计评分 0–3（含左右各自比例）、后爪间距 |
| 圆筒 | 左、右、双爪次数。设置损伤侧后另有对侧使用率、对侧（含½双爪）和不对称指数。还包括竖立次数、各爪触壁时长、达到 20 次用时。每个事件都可在视频上复核并改标签，修改会保留 |
| 步态 | 速度及其变异系数、前后肢步幅、步频、支撑相、摆动相、占空比、支撑面宽度、足印位置、肢间相位（LH→RH、LF→RF、LH→LF、LH→RF）及一致性 R、规律性指数、左右不对称。图表包括足落图、各爪参数表、相位盘、足印分布图 |

所有阈值都以体长（鼻尖到尾根距离的中位数）为单位，换相机或换视野后仍然适用。每个定义和参考文献见“设置 › 方法与参考文献”。

## 已完成的验证

- 所有 Swift 文件已通过语法解析（tree-sitter）。本环境没有 Xcode，**尚未用 iOS SDK 编译**。请在 Xcode 中编译一次，如有报错发给我。
- 三个分析器已逐行移植到 Python，并在已知真值的模拟数据上测试：
  - **步态**（100 fps 小跑，1.5 像素噪声）：步幅、步频、支撑面宽度和相位都准确；占空比为 0.59，真值 0.60。30 fps 时占空比约有 1 帧的偏差，App 会给出提示。
  - **悬尾**：不动时间 163.5 秒，真值 165.4 秒；逐帧一致率 99.2%。
  - **圆筒**：9 次竖立全部判对，在 3 像素噪声加 20% 爪丢失时同样如此。
- 默认参数根据这些测试调整：支撑相速度比为 0.8，步态平滑窗口为 0.03 秒。支撑相取前后两步中较小的位移，因此不会丢掉着地帧和离地帧。

## 局限

- V2 是用**圆筒**视频训练的。悬尾和步态的拍摄视角不同，关键点可能不够准确。每个结果都会显示姿态覆盖率，覆盖率低时会给出警告。请在回放中检查叠加的关键点。如果爪的追踪效果差，建议从这两种拍摄条件中标注一些帧，加入 V2 的训练集。
- 抱握评分是自动估计，请目视确认。
- 步态指标受速度影响。请在相近速度下比较组别，或把速度作为协变量；导出文件中有每一步的速度。
