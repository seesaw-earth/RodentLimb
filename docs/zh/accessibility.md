# 无障碍

RodentLimb 使用 Apple 的标准控件（SwiftUI 和 macOS 原生表格），因此在 macOS 将系统外观设置应用于标准控件时，会遵循深色模式、增强对比度和降低透明度等设置。

## 在 Mac 上

- **键盘优先。** 每个主要命令都有菜单项，大多数有快捷键，包括导入、识别、QC 复核（**I** 纳入、**E** 排除、↑ / ↓ 下一段视频）、事件改标（1–9、0）以及逐帧播放。见[快捷键](./guide/shortcuts.md)。
- **旁白（VoiceOver）。** 菜单、表格、按钮、滑块和文本框都使用旁白可以朗读的标准控件。视频画面、关键点叠加和图表是视觉内容；图表中的每个数字也都在指标表和导出的 CSV 文件中。
- **不只靠颜色。** 事件标签和 QC 结论都以文字显示，不只用颜色表示。
- **语言。** 英文或简体中文，可在 App 内切换。

## 本网站

本手册是静态网站，有语义化标题、搜索框、始终可见的语言切换、浅色和深色主题，以及适配手机的布局。表格包含与相应图示相同的信息。

## 已知局限

- 复核姿态质量和行为事件需要观看视频。如果你无法观看视频，请请同事确认一部分事件。
- 部分图表还没有完整的旁白描述；请改用指标表或导出文件。
