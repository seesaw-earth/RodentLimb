# 姿态模型与来源

RodentLimb 用一个通过 Core ML 在 Mac 上运行的姿态模型找出身体关键点，每段视频只运行一次。RodentLimb for Mac 自带两个模型；导入时按录像的光照条件为每段视频选择一个。

| | [CylinderPose7](./cylinderpose7.md) | [PalmReaderPose8](./palmreader8.md) |
|---|---|---|
| **适用** | 普通室内光（彩色或灰度），通常从透明底板下方拍摄 | 黑暗中的近红外光，从下方拍摄（暗箱 / Blackbox 类装置） |
| **App 中的选项** | *可见光（默认）* | *近红外（暗箱）* |
| **文件** | `CylinderPose7_FP16_640.mlpackage`（19 MB） | `PalmReaderPose8_640_W8A16.mlpackage`（9.8 MB） |
| **网络** | Ultralytics YOLO26s-pose，输入 640 × 640 | Ultralytics YOLO26s-pose，输入 640 × 640 |
| **关键点** | 7 个：左/右前爪、左/右后爪、尾根、鼻尖、嘴 | 8 个：尾根、身体中心、颈部、吻端、左/右后爪、左/右前爪 |
| **训练数据** | 一个实验室的圆筒实验录像：543 帧人工标注 + 20,000 帧清洗后的 DeepLabCut 伪标签 | Barkai 等（2025）随论文公开的 DeepLabCut 训练集中 409 帧人工标注，Zenodo 10.5281/zenodo.16321240 |
| **测试结果** | 80 帧留出的人工标注：平均误差 0.035 体长，96% 的点在 0.1 体长以内 | 37 帧留出的人工标注：中位误差 9.8 像素，77% 的点在 0.1 体长以内 |
| **App 中的精度** | 半精度（FP16）权重 | 8 位调色板量化权重，FP16 计算 |
| **模型包中的许可字段** | AGPL-3.0（导出时由 Ultralytics 写入） | AGPL-3.0（导出时由 Ultralytics 写入） |

两个测试结果之间不能直接比较：视频、画面尺寸和关键点数量都不同。各模型页面说明了数字是怎么得到的。

## 所有视频同一种格式

无论用哪个模型，RodentLimb 为每段视频保存同样的七个关键点（`pose.bin`）：四只爪、尾根、鼻尖和嘴。因此所有任务、质控、复核和导出的工作方式都一样。

- **CylinderPose7** 正好输出这七个点。
- **PalmReaderPose8** 输出八个点。吻端存为鼻尖，四只爪和尾根保持原名，身体中心和颈部不保存。它**没有嘴的关键点**，所以嘴保持缺失；任务需要嘴时（舔爪、面部理毛）改用鼻尖，与嘴没有被识别时的处理相同。

每段视频用哪个模型识别会随视频保存，并写入每次导出：`qc_videos.csv` 的 `pose_model` 列、导出清单（manifest）和方法学段落的第一句。同一研究的所有视频请用同一个模型识别。

## 以前的视频和 iPhone 版

1.3.5 之前，可见光模型是 `CylinderMousePoseV2`，即同一个训练好的网络以全精度（FP32，38 MB）保存。CylinderPose7 是这个网络的半精度版本：104 个权重张量的最大相对差为 0.044%，关键点只有舍入级别的差异。以前在 Mac 或 iPhone 上识别的视频保留原来的关键点，导出时标为 `CylinderMousePoseV2`。

## 模型在 App 中如何运行

每一帧解码后由 Apple 的 Vision 框架等比缩放并补边到 640 × 640，模型给出候选检测，保留置信度最高的一只小鼠（每段视频一只），再把它的关键点映射回原始画面。置信度低于阈值的关键点视为缺失。详见[姿态模型与预处理](../principles/pose.md)。

## 许可与再使用

- 两个模型包都用 Ultralytics YOLO 训练和导出；除非适用 Ultralytics 企业许可，否则其许可为 AGPL-3.0，Ultralytics 写入每个模型包的许可字段为 AGPL-3.0。
- CylinderPose7 用一个实验室的录像训练；这些录像是否公开，见其页面说明。
- PalmReaderPose8 用公开的 DeepLabCut 训练集训练；其许可条款以 Zenodo 记录为准。
- 模型包含在 App 中，并不意味着可以再分发模型或其训练数据。

测试分数描述的是在训练实验室的留出帧上与人工标注的一致性，并不能验证行为指标。在一项研究中依赖某个模型之前，请在自己的视频上检查关键点叠加，并把评分结果与人工评分比较。见[验证与局限](../principles/validation.md)。
