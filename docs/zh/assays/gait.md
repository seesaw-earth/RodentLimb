# 步态分析

RodentLimb 从行走小鼠的仰视视频中，测量每只爪的**支撑相**（着地）和**摆动相**（离地），再计算空间、时间和协调指标。方法参照 LocoMouse（Machado 等，2015）、CatWalk 类指标（Hamers 等，2001），以及 Sheppard 等（2022）的逐步幅分析方法，包括其对行走速度的处理。

## 拍摄

直线步道的仰视拍摄，**≥ 60 fps**。如需厘米单位，在画面中放一次标尺。见[拍摄要点](../guide/recording.md#步态分析)。

## 支撑相与摆动相

爪静止在地面上即为支撑相。每一帧取该爪**前后两步位移中较小的一个**作为速度，这样着地帧和离地帧不会被漏掉（中心差分会漏掉它们）。速度低于下式时为支撑相：

> max（*支撑相速度下限* × BL/s，*支撑相速度比* × 身体速度）

身体速度为鼻尖与尾根中点的速度。短于“最短相位”（30 毫秒）的相位会并入相邻相位。每次支撑相对应一个**足印**，即支撑期间爪的平均位置。

## 哪些步幅计入

只有满足以下条件的步幅才计入：

- 时长不超过“最长步幅时长”（1 秒）；
- 身体速度不低于“最低行走速度”（1.0 BL/s）；
- **直线行走**：平均角速度绝对值 ≤“最大转向角速度”（30 °/s；Sheppard 等使用 ±20 °/s）；
- **不是每段连续行走的首尾步幅**，因为此时小鼠在加速或减速（可关闭）。

“因转向排除的步幅”告诉你有多少步幅因转向被排除。

## 指标

### 速度

| 指标 | 定义 |
|---|---|
| 行走速度 | 计入步幅的平均身体速度（cm/s 或 BL/s） |
| 速度变异系数 | 步幅速度的标准差 ÷ 均值 |
| 分析步幅数、行走时间占比 | 数量，以及速度高于最低行走速度的帧比例 |

### 空间参数

| 指标 | 定义 |
|---|---|
| 步幅（前肢、后肢；后肢另给体长单位） | 同一只爪相邻两个足印的距离 |
| 后肢步长 | 左后爪足印到下一个右后爪足印沿行走方向的距离 |
| 支撑面宽度（前肢、后肢） | 左右足印在垂直于行走方向上的距离（步宽） |
| 足印位置（左、右） | 后爪足印与同侧前一个前爪足印之间的距离 |

### 时间参数

| 指标 | 定义 |
|---|---|
| 步频 | 1 ÷ 后肢平均步幅时长 |
| 支撑相、摆动相（前肢、后肢） | 时长 |
| 占空比（前肢、后肢） | 支撑相 ÷ 步幅时长 × 100 |

### 速度匹配值

几乎所有步态指标都随速度变化（Batka 等，2014），因此直接比较行走速度不同的组的原始均值可能产生误导。RodentLimb 对每只动物拟合该指标随步幅速度变化的直线，读取**参考速度**（默认 2.0 BL/s）处的数值：

- 后肢步幅（BL）、步频、后肢占空比和后肢摆动相 **@ 参考速度**。

需要至少 8 个速度有一定差异的后肢步幅。如果动物从未在参考速度附近行走（超出其实际速度范围的 0.75–1.25 倍），则留空而不外推。整个研究请使用同一个参考速度。如果你更想用以速度为协变量的混合模型（Sheppard 等，2022），步幅导出表中有每一步的速度。

### 变异与对称

| 指标 | 定义 |
|---|---|
| 步幅 / 步时变异系数 | 后肢步幅的标准差 ÷ 均值；共济失调时升高（Machado 等，2015） |
| 后肢步幅左右不对称 | （左 − 右）÷ 左右均值 × 100 |

### 协调

| 指标 | 定义 |
|---|---|
| 肢间相位 | （目标爪着地 − 参考爪着地）÷ 参考爪步幅时长，包括 LH→RH、LF→RF、LH→LF、LH→RF；圆形均值，0–1 |
| 后肢耦合强度 R | LH→RH 相位的合成向量长度：1 = 完全一致，0 = 随机 |
| 规律性指数 | 4 × 正常步序模式数 ÷ 着地次数 × 100（Cheng 等，1997） |
| 步态模式（慢走、小跑、跑步、跳跃 %） | 按每个后肢步幅分类，参照 Bellardita & Kiehn（2015）：后肢相位 0.5 ± 0.15 → *慢走*，若对角（LH→RF）相位为 0 ± 0.15 则为*小跑*；后肢相位 0 ± 0.15 → *跳跃*；其余为*跑步* |

相位 **0.5** 表示两只爪交替，**0 或 1** 表示同步。

### 全身姿态

| 指标 | 定义 |
|---|---|
| 鼻尖 / 尾根侧向摆动 | 每个步幅内，该点相对“步幅起止时身体中心连线”的左右摆动幅度，单位 BL（Sheppard 等，2022） |
| 鼻尖 / 尾根摆动相位 | 该点偏到一侧最远时处于步幅中的位置（圆形均值，0–1） |

## 参数

| 参数 | 默认值 | 作用 |
|---|---|---|
| 支撑相速度比 | 0.8 × 身体速度 | 在 30–100 fps 模拟数据上偏差最小的值 |
| 支撑相速度下限 | 0.8 BL/s | 身体移动很慢时使用的最低阈值 |
| 最短相位 | 0.03 秒 | 更短的支撑/摆动抖动会被合并 |
| 交换左右标签 | 关 | 用于镜像画面 |
| 最低行走速度 | 1.0 BL/s | 更慢的步幅不计入 |
| 最大转向角速度 | 30 °/s | 转向更快时的步幅不计入 |
| 去掉每段行走的首尾步幅 | 开 | 排除加速和减速 |
| 最长步幅时长 | 1.0 秒 | 更长的间隔视为停顿，不算步幅 |
| 参考速度 | 2.0 BL/s | 用于速度匹配值 |
| 位置平滑 | 0.03 秒 | 比其他范式更轻，因为摆动相只有约 0.1 秒 |
