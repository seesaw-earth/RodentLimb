# 步态分析

RodentLimb 从行走小鼠的仰视视频中测量每只爪的**支撑相**（着地）和**摆动相**（悬空），再计算空间、时间和协调性指标。方法参考 LocoMouse（Machado 等，2015）、CatWalk 类指标（Hamers 等，2001）以及 Sheppard 等（2022）的步幅级方法，包括其对行走速度的处理。

## 拍摄

从笔直走道的下方拍摄，**≥ 60 fps**。如果需要厘米单位，让尺子在画面中出现一次。见[拍摄视频](../guide/recording.md#per-task)。

## 支撑相与摆动相

爪静止着地时处于支撑相。每一帧取该爪**向后一步和向前一步位移中较小的那个**作为速度。这样着地和离地那一帧仍算支撑相，而中心差分会漏掉它们。当这个速度低于下式时，爪处于支撑相：

> max( *支撑速度下限* × 体长/秒 , *支撑速度比例* × 身体速度 )

身体速度是鼻尖与尾根中点的速度。短于*最短相位*（30 毫秒）的相位并入相邻相位。每个支撑相有一个**足印**：该支撑相内爪的平均位置。

## 哪些步幅计入

只保留满足以下条件的步幅：

- 持续时间不超过*最长步幅*（1 秒）；
- 身体移动速度至少达到*最低行走速度*（1.0 体长/秒）；
- 小鼠**直行**：平均 |角速度| ≤ *最大转向速率*（30°/秒；Sheppard 等使用 ±20°/秒）；
- **不是一次连续行走的第一个或最后一个步幅**，那时小鼠在加速或减速（可以关闭）。

*因转向排除的步幅*告诉你有多少步幅因转向而被剔除。

## 指标

### 速度

| 指标 | 定义 |
|---|---|
| 行走速度 | 分析步幅的平均身体速度（cm/秒 或 体长/秒） |
| 速度变异（CV） | 步幅速度的 SD ÷ 均值 |
| 分析的步幅数 · 行走时间 | 计数，以及速度高于最低速度的帧所占百分比 |

### 空间

| 指标 | 定义 |
|---|---|
| 步幅长度（前爪、后爪；后爪以体长计） | 同一只爪相邻两个足印之间的距离 |
| 步长，后爪 | 沿行走方向，从左后爪足印到下一个右后爪足印的距离 |
| 支撑基宽（前爪、后爪） | 左右足印之间垂直于行走方向的横向距离（步宽） |
| 足印位置（左、右） | 同侧后爪足印与前一个前爪足印之间的距离 |

### 时间

| 指标 | 定义 |
|---|---|
| 步频 | 1 ÷ 后爪平均步幅时长 |
| 支撑相、摆动相（前爪、后爪） | 时长 |
| 占空比（前爪、后爪） | 支撑相 ÷ 步幅时长 × 100 |

### 速度匹配值

几乎所有步态指标都随速度变化（Batka 等，2014），因此直接比较以不同速度行走的组的原始均值可能产生误导。对每只动物，RodentLimb 以步幅速度为自变量对指标拟合一条直线，并读取**参考速度**（默认 2.0 体长/秒）处的值：

- 后爪步幅长度（体长）、步频、后爪占空比和后爪摆动相 **@ 参考速度**。

至少需要 8 个速度有一定差异的后爪步幅。如果动物从未以接近参考速度的速度行走（超出其观测范围的 0.75×–1.25×），该值留空而不是外推。整个研究请使用同一参考速度。如果你更想用以速度为协变量的混合模型（Sheppard 等，2022），步幅导出中有每个步幅的速度。

### 变异与对称性

| 指标 | 定义 |
|---|---|
| 步幅长度 / 时长变异（CV） | 后爪步幅的 SD ÷ 均值；共济失调时增大（Machado 等，2015） |
| 后爪步幅左右不对称 | 步幅长度的（L − R）÷ mean(L, R) × 100 |

### 协调性

| 指标 | 定义 |
|---|---|
| 肢间相位 | （目标爪着地 − 参照爪着地）÷ 参照步幅，计算 LH→RH、LF→RF、LH→LF 和 LH→RF。圆形均值，0–1 |
| 后爪耦合强度（R） | LH→RH 相位的合成向量长度：1 = 完全一致，0 = 随机 |
| 规律性指数 | 4 × 正常步序模式数 ÷ 爪放置数 × 100（Cheng 等，1997） |
| 步态模式（% 行走、小跑、奔跑、跳跃） | 按后爪步幅，参照 Bellardita & Kiehn（2015）：后爪相位 0.5 ± 0.15 → *行走*，若对角（LH→RF）相位为 0 ± 0.15 则为*小跑*；后爪相位 0 ± 0.15 → *跳跃*；其余为*奔跑* |

相位 **0.5** 表示两只爪交替；**0 或 1** 表示同步。

### 全身姿态

| 指标 | 定义 |
|---|---|
| 鼻尖 / 尾根横向摆动 | 每个步幅内，该点相对于步幅起止时身体中心连线的左右摆动范围，以体长计（Sheppard 等，2022） |
| 鼻尖 / 尾根摆动相位 | 该点在步幅中偏向一侧最远的时刻（圆形均值，0–1） |

## 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| 支撑速度比例 | 0.8 × 身体速度 | 在 30–100 fps 的模拟行走中偏差最小的值 |
| 支撑速度下限 | 0.8 体长/秒 | 身体缓慢时的最低阈值 |
| 最短相位 | 0.03 秒 | 更短的支撑/摆动抖动被合并 |
| 交换左右标签 | 关 | 用于镜像视角 |
| 最低行走速度 | 1.0 体长/秒 | 慢于此的步幅被忽略 |
| 最大转向速率 | 30°/秒 | 转向更快时的步幅被忽略 |
| 去掉每次行走的首尾步幅 | 开 | 去除加速和减速 |
| 最长步幅 | 1.0 秒 | 更长的间隔是停顿，不是步幅 |
| 参考速度 | 2.0 体长/秒 | 用于速度匹配值 |
| 位置平滑 | 0.03 秒 | 比其他任务轻，因为摆动相只有约 0.1 秒 |

## 预设

| 预设 | 设置 | 来源 |
|---|---|---|
| **App 默认** | ≥ 1 体长/秒，转向 ≤ 30°/秒，去掉每次行走的首尾步幅 | RodentLimb 模拟 |
| 旷场步幅（JAX） | 约 0.5 体长/秒（尾根 ≥ 5 cm/秒），转向 ±20°/秒，关键点置信度 > 0.3 | Sheppard 等，2022 |
