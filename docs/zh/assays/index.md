# 实验任务

RodentLimb 用同一组关键点完成七项任务的评分。一段视频只识别一次；之后可以对它运行多个任务，并随时修改任何参数。

  <a class="tst" href="./tail-suspension.html"><strong>悬尾实验</strong><span>不动时间、潜伏期、不动回合、逐分钟曲线、爬尾和估计的抱握评分。</span></a>
  <a class="cyl" href="./cylinder.html"><strong>圆筒实验</strong><span>站立时前爪触壁：左、右、双爪，以及相对损伤侧的不对称性。</span></a>
  <a class="gait" href="./gait.html"><strong>步态分析</strong><span>支撑相、摆动相、步幅、占空比、支撑基宽、肢间相位、步态模式和摆动。</span></a>
  <a class="itch" href="./itch.html"><strong>瘙痒</strong><span>后爪抓挠回合、时间、潜伏期和抓挠串；面颊模型中的前爪擦拭。</span></a>

## 所有任务通用

- 每段视频一只小鼠。姿态模型在每一帧中找出七个关键点（[姿态模型与预处理](../principles/pose.md)）。
- 计算任何指标之前，先清洗位置数据（置信度筛选、缺口填补、平滑）。
- 距离和速度以**体长**（鼻尖–尾根距离的中位数）为单位，除非标定了厘米刻度（步态）。
- 每个结果都列出**姿态覆盖率**。覆盖率低时会有提示，请谨慎解读指标。
- 检测后可以修改任何参数，**实验方案预设**会设置已发表的时间窗；见[参数](../guide/parameters.md)。
- 每个检测到的事件都可以在视频上复核并改标；修改次数会被报告。
- 导出中的**方法学文字**说明评分方法、你的参数值和参考文献。

## 运动功能测试

| | 悬尾实验 | 圆筒实验 | 步态分析 |
|---|---|---|---|
| 相机 | 悬挂小鼠的正面 / 背面 | 下方（或侧面） | 走道下方 |
| 标定 | — | 边缘圆或地面线 | 可选厘米标尺 |
| 主要指标 | 不动时间 秒 / % | 对侧使用率、不对称性 | 步幅、占空比、支撑基宽 |
| 复核 | 运动曲线、视频 | 每次触壁都可改标 | 落足模式、视频 |

## 注射后的行为

| | 瘙痒 | 自发痛行为 | 自我理毛 | 癫痫发作评分 |
|---|---|---|---|---|
| 相机 | 下方，透明底板 | 下方，注射爪可见 | 下方 | 下方 |
| 时间零点 | 注射时刻 | 注射时刻 | 视频开始 | 注射时刻 |
| 主要指标 | 抓挠回合、时间、潜伏期 | 各相舔咬时间、甩爪 | 理毛时间、回合、微结构 | 最高分级、潜伏期 |
| 默认时间窗 | 30 分钟，5 分钟分箱 | I 相 0–10，II 相 10–60 分钟 | 0–10 分钟，1 分钟分箱 | 30 分钟，1 分钟分箱 |
| 复核 | 每个回合 | 每次舔咬和甩爪 | 每个回合 | 每个事件，确认分级 |

::: warning 先初筛，再复核
这四项行为任务的阈值是在模拟数据上设定的，尚未与真实视频的人工评分进行验证。报告结果前，请复核事件，并在部分视频上与盲法人工评分比较。见[验证](../principles/validation.md)。
:::
