## 共同点

- 每段视频一只小鼠。姿态模型逐帧找出 7 个关键点（[姿态模型与预处理](../principles/pose.md)）。
- 计算任何指标前，先对位置进行预处理：置信度过滤、补缺、平滑。
- 距离和速度以**体长（BL）**为单位（鼻尖—尾根距离的中位数），步态标定厘米标尺后改用厘米。
- 每个结果都列出**姿态覆盖率**。覆盖率低时会有提示，相应指标需谨慎解读。
- 所有参数都可以在识别后修改，见[参数](../guide/parameters.md)。

| | 悬尾 | 圆筒 | 步态 |
|---|---|---|---|
| 拍摄 | 悬挂小鼠的正面 / 背面 | 仰视（或侧视） | 步道下方仰视 |
| 标定 | — | 边缘圆圈或地面线 | 可选厘米标尺 |
| 关键指标 | 不动时间 / 比例 | 对侧使用率、不对称指数 | 步幅、占空比、支撑面宽度 |
| 人工复核 | 运动曲线、视频 | 每次触壁可改标签 | 足落模式、视频 |
