# 圆筒实验

圆筒实验（Schallert 等，2000）测量**前肢使用的不对称性**。把小鼠放进透明圆筒，它会站立并用前爪触碰筒壁。单侧损伤（卒中、6-OHDA、皮层损伤）后，损伤对侧的爪使用减少。

## 拍摄与标定

透过透明底板从下方拍摄效果最好；侧面拍摄也可以。在[标定](../guide/calibration.md)中标出**圆筒边缘的圆**（仰视）或**地面线**（侧视）。没有标定就找不到触壁，结果会提示你先标定。

## 如何检测触壁

在某一帧中，前爪同时满足以下两条时算作**在壁上**：

- **静止**：速度低于*静止爪速度*（0.8 体长/秒）；
- **在筒壁处**：
  - 仰视：位于边缘的*触壁区*内（半径外侧 15%）；
  - 侧视：高于地面线至少*爪高度*（0.30 体长）。

一两帧的缺失会被连接起来。持续时间至少达到*最短触壁*（0.10 秒）的连续帧算作一次**放置**。

## 从放置到评分

- **站立**：间隔小于*站立间隔*（0.5 秒）的放置属于同一次站立。
- **每次站立的首次触壁**（默认，Schallert 等，2000）：每次站立中，第一个放上去的爪计为*左*或*右*。如果另一只爪在*同时判定窗口*（0.2 秒）内跟上，这次站立计为*双爪*。
- **每次触壁**：每次放置都计分。在同时判定窗口内开始的左右放置合并为*双爪*。
- **限制**：可以只计前 N 秒或前 N 次触壁（有些方案使用前 20 次触壁或 3–5 分钟）。

## 检查与修正

打开**回放**。每次触壁都和时间一起列出。选中即可播放（↑ / ↓ 在列表中逐个切换）；如果自动判断有误，用数字键把标签改为*左、右、双爪*或*忽略*。修改按帧保存，参数改变时保留，计入*人工修改事件*，并在片段表中导出（自动标签和复核后标签）。

## 指标

| 指标 | 定义 |
|---|---|
| 计分的触壁次数 | 左 + 右 + 双爪（修改和限制之后） |
| 左爪 / 右爪 / 双爪 | 次数 |
| 左 / 右 / 双爪（占全部的 %） | 次数 ÷ 总数 × 100 |
| **对侧使用率** | 对侧 ÷（同侧 + 对侧）× 100（Magno 等，2019） |
| 对侧（含 ½ 双爪） | （对侧 + ½ 双爪）÷ 总数 × 100 |
| **不对称指数** | （同侧 − 对侧）÷（同侧 + 对侧 + 双爪）× 100 |
| 同侧 / 对侧 | 相对损伤半球的次数 |
| 左爪使用率 L/(L+R) · 左 − 右偏向 | 未设置损伤侧时显示 |
| 有触壁的站立次数 | 站立次数 |
| 爪在壁上的时间（秒）、平均放置时长（秒） | 每只爪 |
| 达到 20 次触壁的时间 | 第 20 次计分触壁的开始时间 |
| 前爪可见率 | 可见度较低的那只前爪的检测率（% 帧） |

在参数中设置**损伤半球**即可得到相对损伤的指标。左半球损伤时，右爪为对侧。

## 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| 拍摄视角 | 仰视 | 仰视（边缘圆）或侧视（地面线） |
| 损伤半球 | 未设置 | 启用同侧 / 对侧指标 |
| 计分方式 | 每次站立的首次触壁 | 或每次触壁 |
| 交换左右标签 | 关 | 模型的左右指画面左右时使用（镜像视角） |
| 触壁区 | 0.15 × r | 仰视 |
| 爪高度 | 0.30 体长 | 侧视 |
| 静止爪速度 | 0.8 体长/秒 | 漏检触壁时调高；把经过的爪计入时调低 |
| 最短触壁 | 0.10 秒 | 最短的放置 |
| 同时判定窗口 | 0.20 秒 | 在此时间内左 + 右 = 双爪 |
| 站立间隔 | 0.5 秒 | 间隔更短的放置构成同一次站立 |
| 只计前 N 秒 / 前 N 次 | 无 | 时间或次数限制 |

## 预设

| 预设 | 设置 | 来源 |
|---|---|---|
| 前 20 次触壁 | 记满 20 次触壁后停止计分 | Schallert 等，2000 |
| 5 分钟实验 | 前 5 分钟内的全部触壁 | Bentea 等，2025（protocols.io） |
| **整段视频**（默认） | 不限 | |
