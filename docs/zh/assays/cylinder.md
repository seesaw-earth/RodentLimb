# 圆筒实验

圆筒实验（Schallert 等，2000）测量**前肢使用的不对称性**。把小鼠放入透明圆筒，它会竖立并用前爪触壁。单侧损伤（卒中、6-OHDA、皮层损伤）后，损伤对侧的前爪使用会减少。

## 拍摄与标定

最好透过透明底面仰视拍摄，侧视也可以。在[标定](../guide/calibration.md)中标出**边缘圆圈**（仰视）或**地面线**（侧视）。未标定时无法检测触壁，结果页会提示你先标定。

## 如何判定触壁

某一帧中，前爪同时满足以下两点即视为**在壁上**：

- **静止**：速度低于“爪静止速度”（0.8 BL/s）；
- **在壁处**：
  - 仰视：位于边缘的“触壁区域”内（半径外侧 15%）；
  - 侧视：高出地面线至少“爪离地高度”（0.30 BL）。

一两帧的短暂丢失会被补上。这类帧连续持续不短于“最短触壁”（0.10 秒）即为一次**放置**。

## 从放置到计分

- **竖立**：相隔小于“竖立间隔”（0.5 秒）的放置属于同一次竖立。
- **每次竖立首次触壁**（默认，Schallert 等，2000）：每次竖立中第一只触壁的爪计为*左*或*右*；如果另一只爪在“同时判定窗口”（0.2 秒）内跟上，则这次竖立计为*双爪*。
- **所有触壁**：每次放置都计分；左右爪在同时判定窗口内先后开始的放置合并为*双爪*。
- **上限**：可只统计前 N 秒或前 N 次触壁（部分方案只统计前 20 次或前 3–5 分钟）。

## 复核与修改

打开“回放”，每次触壁按时间列出。点一下即可播放；如自动判断有误，可改为*左爪、右爪、双爪*或*忽略*。修改按帧保存，修改参数后仍会保留，计入“人工修改事件”，并在 `…_contacts.csv` 中导出（自动标签和最终标签）。

## 指标

| 指标 | 定义 |
|---|---|
| 计分触壁次数 | 左 + 右 + 双（修改和上限之后） |
| 左爪 / 右爪 / 双爪 | 次数 |
| 左 / 右 / 双（占全部） | 次数 ÷ 总数 × 100 |
| **对侧前肢使用率** | 对侧 ÷（同侧 + 对侧）× 100（Magno 等，2019） |
| 对侧（含½双爪） | （对侧 + ½ 双爪）÷ 总数 × 100 |
| **不对称指数** | （同侧 − 对侧）÷（同侧 + 对侧 + 双爪）× 100 |
| 同侧 / 对侧 | 相对损伤半球的次数 |
| 左爪使用率 L/(L+R)、左右偏好指数 | 未设置损伤侧时显示 |
| 触壁竖立次数 | 竖立次数 |
| 触壁总时长、平均每次触壁（秒） | 按爪分别统计 |
| 达到 20 次触壁用时 | 第 20 次计分触壁的开始时间 |
| 前爪可见率 | 两只前爪中可见率较低者（帧比例） |

在参数中设置**损伤半球**即可得到相对损伤侧的指标。左半球损伤时，右爪为对侧。

## 参数

| 参数 | 默认值 | 作用 |
|---|---|---|
| 拍摄视角 | 仰视 | 仰视（边缘圆圈）或侧视（地面线） |
| 损伤半球 | 不设置 | 设置后给出同侧 / 对侧指标 |
| 计分方式 | 每次竖立首次触壁 | 或所有触壁 |
| 交换左右标签 | 关 | 模型的左右指画面左右时（镜像画面）使用 |
| 触壁区域 | 0.15 × 半径 | 仰视 |
| 爪离地高度 | 0.30 BL | 侧视 |
| 爪静止速度 | 0.8 BL/s | 漏检时调高；路过的爪被计入时调低 |
| 最短触壁 | 0.10 秒 | 最短放置时长 |
| 同时判定窗口 | 0.20 秒 | 左右爪在此时间内先后触壁 = 双爪 |
| 竖立间隔 | 0.5 秒 | 间隔更短的放置归为同一次竖立 |
| 仅统计前 / 触壁次数上限 | 不限 | 时间或次数上限 |
