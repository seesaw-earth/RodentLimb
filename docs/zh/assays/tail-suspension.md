# 悬尾实验

悬尾实验（Steru 等，1985）测量小鼠被倒挂时保持不动的时间，作为抗抑郁药筛选中“行为绝望”的指标。RodentLimb 还会标出爬尾，并估计后肢抱握（Guyenet 等，2010）。

## 拍摄

从**正面或背面**拍摄，使两只后爪都可见，从悬挂时开始。标准时长：**6 分钟**。见[拍摄视频](../guide/recording.md#per-task)。

## 不动如何评分

1. **运动信号。** 每一帧计算四只爪和鼻尖的平均速度（体长/秒）。每个关键点的速度上限为 5 体长/秒，避免单个错误检测主导结果。五个点中至少要有两个。尾根位于悬挂点，因此不计入。之后对信号做平滑（*运动平滑*）。
2. **不动帧。** 运动低于**运动阈值**的帧。
3. **不动回合。** 持续时间至少达到**最短不动时长**的连续不动帧才算不动；更短的停顿不算。
4. **时间窗。** 在**分析窗口**内累计不动时间，默认 120–360 秒（第 2–6 分钟），因为几乎所有小鼠在前两分钟都会挣扎（Can 等，2012）。如果视频短于窗口，则使用整段视频，并给出提示。

姿态不足的帧不算作不动；*姿态覆盖率*告诉你这类帧有多少。

## 爬尾

鼻尖到尾根的距离小于**爬尾判定比例** × 体长时，该帧算作爬尾。在窗口内报告*爬尾比例*。许多实验方案会排除爬尾超过测试时间 20% 的动物，App 会在这种情况下给出提示。

## 后肢抱握（估计）

在最初的**抱握评估时长**内（默认 10 秒），App 测量每只后爪到身体轴线（尾根 → 鼻尖）的横向距离（体长）：

- 小于*部分抱握距离*（0.25 体长）= 向中线收拢；
- 小于*完全抱握距离*（0.10 体长）= 完全抱握。

评分改编自 Guyenet 等（2010）：**0** 两只爪收拢的时间都不超过 50%；**1** 一只爪收拢超过 50%；**2** 两只爪部分收拢超过 50%；**3** 两只爪完全收拢超过 50%。

::: warning
这是对视觉评分的自动近似。请在视频上确认，尤其是 1–2 分。
:::

## 指标

| 指标 | 单位 | 定义 |
|---|---|---|
| 不动时间 | 秒 | 窗口内不动回合的时间 |
| 不动比例 | % | 不动时间 ÷ 窗口长度 × 100 |
| 首次不动潜伏期 | 秒 | 第一个符合条件的回合的开始时间，从视频开始算起 |
| 不动次数 | 次 | 与窗口重叠的回合数 |
| 平均 / 最长不动时长 | 秒 | 窗口内回合的时长 |
| 分析窗口 | 秒 | 实际分析的长度 |
| 爬尾比例 | % | 窗口内爬尾帧 ÷ 有姿态的帧 |
| 抱握评分（估计） | 0–3 | 见上文 |
| 左 / 右后爪靠近中线 | % | 抱握评估时长内该爪收拢的时间比例 |
| 后爪间距 | 体长 | 窗口内两只后爪之间的平均距离 |
| 姿态覆盖率 | % | 窗口内能计算运动信号的帧 |

## 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| 窗口起点 / 终点 | 120 / 360 秒 | 评分的视频段 |
| 运动阈值 | 0.25 体长/秒 | 呼吸或震颤被判为活动时调高；被动摆动被判为不动时调低 |
| 最短不动时长 | 1.0 秒 | 算作不动的最短停顿 |
| 运动平滑 | 0.25 秒 | 运动信号的滑动平均 |
| 抱握评估时长 | 10 秒 | 从视频开始算起 |
| 部分 / 完全抱握距离 | 0.25 / 0.10 体长 | 爪到中线的阈值 |
| 爬尾判定比例 | 0.5 体长 | 算作爬尾的鼻尖–尾根距离 |

::: tip 如何选择阈值
打开几段视频，以 2× 速度播放回放标签页，把*不动 / 活动*指示与你自己的判断比较。为整个研究设定一次阈值，然后用 **应用到…** 应用到该任务的所有分析。
:::
