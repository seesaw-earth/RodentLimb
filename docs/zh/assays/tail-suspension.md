# 悬尾实验

悬尾实验（Steru 等，1985）测量小鼠被倒挂时保持不动的时间，作为“行为绝望”的指标，常用于抗抑郁药筛选。RodentLimb 还会标记爬尾，并估计后肢抱握（Guyenet 等，2010）。

## 拍摄

从**正面或背面**拍摄，保证两只后爪可见，从悬挂开始录制。标准时长 **6 分钟**。见[拍摄要点](../guide/recording.md#悬尾实验)。

## 不动如何判定

1. **运动量。** 每一帧计算四只爪和鼻尖的平均速度（体长/秒）。为避免个别错误检测主导结果，每个点的速度上限为 5 BL/s，且五个点中至少需要两个。尾根位于悬挂点，不参与计算。随后对该信号做平滑（“运动平滑”）。
2. **不动帧。** 运动量低于**运动阈值**的帧。
3. **不动时段。** 连续不动帧持续不短于**最短不动时长**才计为不动；更短的停顿不计。
4. **分析窗口。** 在**分析窗口**内累计不动时间，默认 120–360 秒（第 2–6 分钟），因为几乎所有小鼠在前两分钟都会挣扎（Can 等，2012）。视频短于窗口时改为分析整段视频，并给出提示。

姿态不足的帧不计为不动；“姿态覆盖率”说明了这类帧有多少。

## 爬尾

鼻尖到尾根的距离小于**爬尾判定比例** × 体长时，该帧计为爬尾。结果给出窗口内的爬尾比例。许多方案会排除爬尾超过 20% 的动物，出现这种情况时 App 会提示。

## 后肢抱握（估计）

在最初的**抱握评估时长**内（默认 10 秒），测量每只后爪到身体轴线（尾根 → 鼻尖）的横向距离（体长）：

- 小于“部分抱握距离”（0.25 BL）= 向中线收拢；
- 小于“完全抱握距离”（0.10 BL）= 完全抱握。

评分参照 Guyenet 等（2010）：**0** 两只爪收拢时间都不超过 50%；**1** 一只爪收拢超过 50%；**2** 两只爪部分收拢均超过 50%；**3** 两只爪完全抱握均超过 50%。

::: warning
这是对目测评分的自动近似，请在视频上确认，尤其是 1–2 分。
:::

## 指标

| 指标 | 单位 | 定义 |
|---|---|---|
| 不动时间 | 秒 | 窗口内处于不动时段的时间 |
| 不动比例 | % | 不动时间 ÷ 窗口长度 × 100 |
| 首次不动潜伏期 | 秒 | 第一个合格不动时段的起点（从视频开始计） |
| 不动次数 | 次 | 与窗口重叠的不动时段数 |
| 平均 / 最长不动时长 | 秒 | 窗口内不动时段的时长 |
| 分析窗口 | 秒 | 实际分析的长度 |
| 爬尾比例 | % | 窗口内爬尾帧 ÷ 有姿态的帧 |
| 抱握评分（估计） | 0–3 | 见上 |
| 左 / 右后爪靠近中线 | % | 抱握评估时间内该爪收拢的比例 |
| 后爪间距 | BL | 窗口内两只后爪的平均距离 |
| 姿态覆盖率 | % | 窗口内能计算运动量的帧比例 |

## 参数

| 参数 | 默认值 | 作用 |
|---|---|---|
| 窗口起点 / 终点 | 120 / 360 秒 | 统计的时间段 |
| 运动阈值 | 0.25 BL/s | 呼吸或颤抖被判为挣扎时调高；被动摆动被判为不动时调低 |
| 最短不动时长 | 1.0 秒 | 计为不动的最短停顿 |
| 运动平滑 | 0.25 秒 | 运动量的滑动平均窗口 |
| 抱握评估时长 | 10 秒 | 从视频开始计 |
| 部分 / 完全抱握距离 | 0.25 / 0.10 BL | 爪到中线的阈值 |
| 爬尾判定比例 | 0.5 BL | 鼻尖到尾根的距离小于该值计为爬尾 |

::: tip 如何确定阈值
打开几段视频，在“回放”中以 2 倍速播放，对比“不动 / 挣扎”标签与你自己的判断。为整个研究确定一个值，然后用“应用到所有记录”。
:::
