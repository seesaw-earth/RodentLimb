## 报告问题或提问

在 GitHub 上提交 issue：**[github.com/seesaw-earth/RodentLimb/issues](https://github.com/seesaw-earth/RodentLimb/issues)**

为了更快帮到你，请提供：

1. **App 版本**：Mac 上的 **RodentLimb › 关于 RodentLimb**；iPhone 版的设置页。
2. **Mac 型号和 macOS 版本**（苹果菜单 › 关于本机），或 iPhone / iPad 型号和 iOS 版本。
3. **姿态模型**（显示在视频页面）和**任务**。
4. **视频格式**：时长、帧率、分辨率和编码（显示在导入表格和检查器中）。
5. **你做了什么、期望什么、实际发生了什么。**
6. 一张显示关键点的**回放播放器截图**；如果可以分享，再附一段短视频。
7. Mac 上识别失败时，附上活动日志中的相关行（资料库中的 `Logs/`；**文件 › 在访达中显示资料库**）。
8. 导出相关的问题，附上 **CSV 的前几行**，必要时替换真实的动物编号。

::: warning 注意分享的内容
GitHub issue 是公开的。不要发布未发表的数据、可识别身份的信息，或你无权分享的视频。通常一张截图或几行匿名数据就够了。
:::
