## 报告问题或提问

在 GitHub 上提交 issue：**[github.com/seesaw-earth/RodentLimb/issues](https://github.com/seesaw-earth/RodentLimb/issues)**

为了更快帮你解决，请提供：

1. **App 版本**：App 的“设置”页，或 iPhone 设置 › 通用 › iPhone 储存空间 › RodentLimb。
2. **iPhone 或 iPad 型号及 iOS 版本。**
3. **范式**，以及视频大致时长和帧率。
4. **你做了什么、预期是什么、实际发生了什么。**
5. 一张显示关键点的**“回放”页截图**；如果可以分享，再附一小段视频。
6. 关于导出的问题，请附上 **CSV 的前几行**，必要时替换真实的动物编号。

::: warning 注意分享内容
GitHub issue 是公开的。请不要发布未发表的数据、可识别身份的信息，或你无权分享的视频。通常一张截图或几行匿名化数据就足够了。
:::
