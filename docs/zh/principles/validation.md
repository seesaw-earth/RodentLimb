# 验证与局限

RodentLimb 是研究工具。本页列出已经做过的检查，以及在把结果用于研究之前你需要在自己的视频上检查的内容。

## 姿态模型

各模型在留出测试帧上的准确度见其页面：

- [CylinderPose7](../models/cylinderpose7.md#accuracy)——来自未用于训练的录像的测试帧。
- [PalmReaderPose8](../models/palmreader8.md#accuracy)——来自两个留出录像组的 37 个测试帧。

测试帧来自模型训练所用的装置。在你的相机、光照和场地上，准确度可能更低。

## 分析：模拟小鼠

前三项任务的分析器被逐行移植到 Python，并在**已知真值的模拟小鼠**上运行（脚本位于仓库的 `Tools/validation/`）。

### 步态

模拟小跑，20 cm/秒，4 Hz，占空比 0.60，后爪支撑基宽 3 cm，关键点噪声 1–2 像素：

| 指标 | 真值 | RodentLimb |
|---|---|---|
| 步幅长度 | 5.00 cm | 5.00 cm |
| 步频 | 4.00 Hz | 4.00 Hz |
| 占空比（100 fps） | 0.60 | 0.59 |
| 占空比（30 fps） | 0.60 | 0.70 |
| 后爪支撑基宽 | 3.0 cm | 2.98–3.00 cm |
| 步长（后爪） | 25 像素 | 25.6 像素 |
| 鼻尖横向摆动 | 0.133 体长 | 0.129 体长 |
| 参考速度下的步幅长度（混合速度） | 50.0 像素 | 50.2 像素 |
| 相位 LH→RH / LH→RF（小跑） | 0.5 / 0 | 0.49–0.52 / 0.00–0.01 |
| 步态模式（小跑） | 小跑 | 28 个步幅中 26 个为小跑 |
| 以 40°/秒转向时的步幅 | 剔除 | 保留 0 个 |

支撑相检测的默认值（步速 = 向后和向前位移中较小者；支撑速度比例 0.8）是根据这些模拟选定的。30 fps 时占空比约有一帧的偏差，App 在低于 50 fps 时会给出警告。

### 悬尾

模拟 6 分钟实验，随机的活动 / 不动时段，不动时有呼吸运动，噪声 0.8 像素：不动时间 **163.5 秒，真值 165.4 秒**；潜伏期 **5.7 秒，真值 5.6 秒**；逐帧一致率 **99.2%**。

### 圆筒

模拟仰视实验，9 次设定好的站立（左先、右先、双爪）：**9 / 9** 标注正确，在 3 像素噪声和 20% 爪检测缺失时同样如此。

### 瘙痒、疼痛、理毛和癫痫

这些任务的时间窗、分相和分箱遵循已发表的实验方案（见各任务页面的预设）。检测阈值——以体长为单位的距离和速度、运动能量——是在模拟数据上设定的，**尚未与真实视频的人工评分进行验证**。请把这四项任务视为初筛：每个检测到的事件都列出供复核，方法学文字会统计你修改了多少。

## 软件测试

Mac 版的分析代码与 iPhone 版相同（逐字节核对）。共享层和核心层的自动测试包括：

- **中断识别**：5,000 帧的运行在第 3,100 帧停止后从检查点继续，得到逐位相同的关键点；`pose.bin` 读回无损。
- **批处理**（模拟模型）：暂停与继续，坏文件失败并写明原因，从检查点重试，离线硬盘在队列中等待。
- **导出**：每张表都用 pandas 读回；片段时长 = 结束 − 开始；DeepLabCut 文件用 `header=[0,1,2]` 读出（7 个部位 × x, y, likelihood）。
- **姿态模型**：各模型的关键点映射（PalmReaderPose8：吻端 → 鼻尖、四爪、尾根、无嘴）、输出布局、`pose.bin` 中记录的模型名、QC 表和方法学文字。
- **资料库安全**：最近删除、恢复、备份和资料库锁。
- **预设**：每个预设可重复应用、保留每只动物自己的设置、能被识别。

## 你需要检查什么

模拟检验的是**分析**，而不是**姿态模型在你的视频上**的表现。把结果用于研究之前：

1. 在回放播放器中**检查几段视频的关键点叠加**。每个关键点是否在正确的身体部位上，左右是否正确？
2. **盲法人工评分一部分视频**，例如 10% 的动物，并比较：不动时间、触壁次数、步幅指标、抓挠回合、舔咬时间、理毛时间、发作分级。
3. **固定**与人工评分最一致的参数，应用到研究的所有分析（*应用到…*），并报告这些参数（方法学导出中包含它们）。
4. **复核事件列表**（圆筒触壁和所有行为任务）。修改会被保存和计数。
5. **预先设定纳入标准**（[质量控制](../guide/qc.md)），排除不满足标准的视频。

在方法部分报告一致性（例如相关系数或 Bland–Altman 图）。
