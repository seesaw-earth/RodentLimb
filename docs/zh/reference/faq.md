# 常见问题与排错

## 姿态识别

### “仅 …% 的帧检测到小鼠”

很多帧中没有找到高于检测置信度的小鼠。请检查动物是否完整在画面内、光线是否均匀、画面是否清晰。也可以在“设置”中调低“检测置信度”，然后选择 **⋯ › 重新识别**。

### 爪的位置跳动或左右互换

单帧跳变会被中值滤波去除。如果互换持续较久，说明该视角对模型来说比较陌生（V2 用圆筒视频训练）。调高“关键点置信度”可以去掉不确定的点。根本办法是把你自己实验条件下标注的帧加入训练集。

### 左右颠倒

如果画面是镜像的（通过镜子仰视拍摄时常见），请在参数中打开“交换左右标签”（圆筒和步态）。

### 识别暂停了

iOS 不允许 App 在后台使用 GPU。切换到其他 App 时当前视频会暂停，回到 RodentLimb 后自动继续。处理大批视频时请保持 App 在前台；处理期间屏幕不会自动锁定。

## 悬尾

### 呼吸被判为挣扎，或摆动被判为不动

调整“运动阈值”。在“回放”中播放，观察“不动 / 挣扎”标签。为整个研究确定一个值。

### 抱握评分看起来不对

它需要从正面或背面看到两只后爪，侧面拍摄无法使用。请把它当作估计值，并在视频上确认。

## 圆筒

### 检测不到触壁

请先标定：边缘圆圈（仰视）或地面线（侧视），并确认“拍摄视角”参数与实际一致。

### 漏检或多检触壁

调整“爪静止速度”（调高可检出更多）、“触壁区域”或“爪离地高度”，以及“最短触壁”。然后复核列表并修改剩下的错误，修改会保留。

## 步态

### “只有 N 个步幅通过筛选”

使用更长或更多的行走片段，或放宽“最低行走速度”和“最大转向角速度”。如果小鼠始终没有稳定行走，步态指标本身也不可靠。

### 速度匹配值为空

该动物从未在参考速度附近行走。可以为整个研究调整“参考速度”，或使用原始值并以每步速度作为协变量。

### 占空比偏高

检查帧率：低于 50 fps 时支撑相的时间分辨率很粗，会偏高。请用 60 fps 或更高帧率录制。

这是有意设计的：导出的键名和文字始终为英文，方便脚本和论文使用。动物编号、组别和备注按输入原样保留。
