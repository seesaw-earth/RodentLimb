# 版本说明

## 1.1.2

- **回放更流畅**：拖动进度条时画面和关键点保持同步；在视频上左右滑动可逐帧移动。
- 视频处理期间不再整页重绘界面；保存记录和导出逐帧姿态 CSV 改在后台完成。
- 文字输入：按回车跳到下一个输入框，数字键盘有“完成”键，拖动页面即可收起键盘。

## 1.1

- 新图标，爪的配色与图标一致。
- 界面更简洁：结果分为概览、回放、全部指标三栏；首次启动有简短的欢迎引导；iOS 26 采用 Liquid Glass。
- **步态方法学 v2**：直线行走与行走首尾筛选、参考速度下的速度匹配值、步幅变异系数、步长、步态模式（慢走/小跑/跑步/跳跃）、鼻尖与尾根侧向摆动。
- 1.0 版的结果在首次打开时自动重新计算。

## 1.0

- 首个版本：基于 CylinderMousePoseV2 的悬尾、圆筒和步态分析；中英文界面；CSV 和方法描述导出。
