# 更新说明

## RodentLimb for Mac

### 1.3.5

- **两个姿态模型。** *可见光*——[CylinderPose7](../models/cylinderpose7.md)（FP16，19 MB）——是新导入的默认模型；*近红外（暗箱）*——[PalmReaderPose8](../models/palmreader8.md)——是第二个选项。全精度的 CylinderMousePoseV2 模型包不再随 App 提供，App 因此小了很多。
- 以前识别的视频保留其关键点。没有记录模型的视频（iPhone 资料库、1.3.2 之前的 Mac 版本）在导出中仍标为 CylinderMousePoseV2；`pose_model` 列、方法学文字和 manifest 写明每段视频实际使用的模型。
- **导入时检查视频能否解码。** RodentLimb 询问 macOS 能否解码每个文件，并试解一帧。没有解码器的格式（例如 M1 和 M2 Mac 上的 AV1）标为*无法读取*，并说明如何转换为 H.264 MP4。这类视频现在会立即失败并写明原因，不再重试。

### 1.3.3

- CylinderPose7 FP16：可见光网络的半精度版本——每个权重与全精度模型的相对差在 0.044% 以内——体积减半。
- 重新识别菜单、队列卡片和检查器用不同名称区分各模型。`qc_videos.csv` 的 `pose_model` 列写模型全名。

### 1.3.2

- **近红外模型** PalmReaderPose8，用于黑暗中近红外光照明、从下方拍摄的视频（暗箱 / Blackbox 类装置）。
- 导入时选择模型；在视频页面或表格右键菜单中用另一个模型重新识别；在 **设置 › 处理** 中设置默认模型。
- 模型的关键点映射到保存的七个点（吻端 → 鼻尖；该模型没有嘴，分析改用鼻尖），因此分析、QC、复核和导出不变。视频页、检查器、队列、分析和概览都显示所用模型，并写入每次导出。

### 1.3.1

- 修复打开*待复核*、*全部视频*或研究页面时卡住并闪退的问题。
- 识别完成后，处理队列页列出下一步：等待 QC 决定的视频、已纳入但没有任务的视频、可以打开的分析。
- **简体中文**界面，可在 App 内切换（菜单 **RodentLimb › Language · 语言**、侧栏中的地球图标、欢迎页或设置）。
- **数据安全**：最近删除（30 天，可撤销）、删除和批量修改前自动备份、纳入决定立即保存，以及两台 Mac 打开同一资料库时的提醒。
- 大型资料库更快（索引查找）。
- 每个分析参数中新增**实验方案预设**，对应已发表的方案。见[参数](../guide/parameters.md)。

### 1.3

第一个 Mac 版本。分析代码与 iPhone 版相同。

- **批量处理**：拖入文件或文件夹；根据文件名建议动物、时间点和试次；同时识别 1–3 段视频，显示实时画面、进度和剩余时间；暂停、继续、调整顺序和取消；逐帧检查点；自动重试；离线硬盘在队列中等待；磁盘空间不足时暂停；活动日志。
- **资料库**：与 iPhone 版相同的文件夹结构；视频原位引用；可排序的原生表格和检查器；键盘复核。
- **导出**所选内容、一个任务、一个研究或整个资料库，附数据字典和清单；所有视频的事件 / 回合汇总表；BORIS、DeepEthogram / daart 和 DeepLabCut 格式。
- 七项任务：悬尾、圆筒、步态、瘙痒、自发痛行为、自我理毛和癫痫发作评分。
- Mac 上不提供：录制视频，以及渲染骨架视频。

## RodentLimb for iPhone

### 1.1.2

- **流畅的回放**：拖动时画面和关键点保持同步。在视频上左右轻扫可逐帧步进。
- 处理视频时界面不再整屏重绘。保存和姿态 CSV 导出在后台进行。
- 输入：回车跳到下一个字段，数字键盘带“完成”键，拖动即可收起键盘。

### 1.1

- 新的 App 图标；爪的颜色与图标一致。
- 更简洁的界面。结果有三个标签页：概览、回放和指标。首次启动有简短的欢迎导览。iOS 26 上使用 Liquid Glass。
- **步态方法 v2**：直行和行走首尾筛选、参考速度下的速度匹配值、步幅变异（CV）、步长、步态模式（行走/小跑/奔跑/跳跃）、鼻尖和尾根的横向摆动。
- 1.0 的结果在首次打开时自动重新计算。

### 1.0

- 第一个版本：使用 CylinderMousePoseV2 的悬尾、圆筒和步态分析；中英文界面；CSV 和方法学导出。
