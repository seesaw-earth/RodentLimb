# 标定

标定告诉 App 装置在画面中的位置。**圆筒实验**必需，**步态**可选，**悬尾**不需要。

可从记录页底部栏的“标定”打开，或在需要标定时出现的卡片中打开。视频还在排队时也可以先做标定。

## 选择画面

- 拖动**画面时刻滑块**，选一个装置清晰可见的时刻。
- 画面上会画出该帧的关键点，方便定位。
- 拖动控制点时，**放大镜**会放大手指下方的区域。

## 圆筒仰视：边缘圆圈

在圆圈**内部**拖动可移动，拖动圆**边**可调整大小。使其与圆筒底面内缘重合。虚线内圈表示**触壁区域**：静止的爪落在两圈之间即视为在壁上。

“根据追踪自动拟合”会按整段视频中关键点经过的范围拟合圆圈。小鼠会探索整个底面，所以这通常是个好的起点。

## 圆筒侧视：地面线

把虚线拖到圆筒底面。“根据后爪位置估计”会把它放在后爪最低的位置。前爪高出这条线达到“爪离地高度”参数时，视为抬起。

## 步态：厘米标尺

把两端拖到已知距离的两个标记上（标尺或步道宽度），然后输入距离。App 会显示得到的像素/厘米。“移除标尺”会回到体长单位。

## 复用标定

- “仅保存到本视频”只保存当前记录。
- “保存并用于该范式的所有视频”会复制到该范式的每条记录。仅在相机没有移动时这样做。

新建的记录会自动沿用同一范式上一条记录的标定和参数，结果页会提示你检查。
