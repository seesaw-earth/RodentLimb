# 快捷键

| 位置 | 快捷键 |
|---|---|
| 全局 | ⌘O 导入视频 · ⇧⌘N 新建研究 · ⌥⌘O 打开资料库 · ⌘E 导出 · ⌘R 开始识别 · ⌘. 暂停 · ⌘, 设置 · ⌘0 主窗口 · ⌥⌘⌫ 最近删除 |
| 侧栏 | ⌘1 概览 · ⌘2 处理队列 · ⌘3 待复核 · ⌘4 全部视频。在**显示**菜单中显示或隐藏侧栏和检查器 |
| 处理队列 | ⌥⌘↑ 移到最前 · ⌥⌘↓ 移到最后 |
| 待复核 | I 纳入 · E 排除（选择原因） · ↑ / ↓ 上一段 / 下一段视频 |
| 结果 | ⌥⌘1 概览 · ⌥⌘2 回放 · ⌥⌘3 全部指标 · ⇧⌘E 导出此分析 · ⌘Z 撤销标签修改 |
| 事件列表 | ↑ / ↓ 上一个 / 下一个事件（视频跟随） · 1–9 修改标签 · 0 忽略 · 空格 播放 / 暂停 |
| 播放器 | 空格 播放 / 暂停 · ← / → 逐帧 · ⇧← / ⇧→ ±1 秒 · J 后退 5 秒 · K 暂停 · L 播放 · , / . 逐帧 |
| 研究页面 | ⇧⌘I 导入视频到此研究 · ⇧⌘D 编辑设计 |
