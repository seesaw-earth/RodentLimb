# 数据、组间比较与导出

## “数据”页

所有记录在一个列表中。

- 按范式**筛选**（全部、TST、CYL、GAIT），按动物编号、组别或文件名**搜索**。
- 在一行上**左滑**可删除。
- “**选择**”可多选，用于导出或删除。
- 选定范式后出现“**组间比较**”。

## 组间比较

选择一个指标。图中显示每组均值（柱）、标准误（误差线）和每只动物（点），并列出 n、均值、标准差和标准误。这里只做描述性统计，统计检验请用导出的 CSV 在常用软件中完成。分组依据是每条记录填写的“组别”。

## 导出单条记录

在记录页点“导出”，得到：

- `…_summary.csv`：记录信息、所有指标（键、值、单位）和提示；
- 该范式的事件：不动时段和逐分钟统计、圆筒触壁列表，或步态的步幅表和足印表；
- `…_methods.txt`：包含参数值和参考文献的方法描述；
- 可选 `…_pose.csv`：逐帧的各关键点 x、y 和置信度；
- 可选骨架 MP4（如果生成过）。

无论界面语言是什么，导出**始终为英文**，可直接用于脚本和论文。列说明见[文件与导出](../reference/files.md)。

## 批量导出

在“数据”页点“选择”，选中记录后点“导出 CSV”。**每个范式得到一个宽表**，每只动物一行（编号、组别、视频、日期、状态，然后是所有指标），这是大多数统计软件需要的格式。

## 文件位置

所有数据保存在 App 的文件夹中，可在“**文件 › 我的 iPhone › RodentLimb**”中看到。每条记录有自己的文件夹，包含视频、姿态数据和结果。见[文件与导出](../reference/files.md)。
