# 拍摄视频

爪在画面中越大、越清晰、光照越均匀，模型就找得越好。在相机设置上多花几分钟，可以省下之后几小时的检查。

## 按光照选择模型

| 你的录像 | 导入时选择的姿态模型 |
|---|---|
| 室内光，彩色或灰度，通常从透明底板下方拍摄 | **可见光** — [CylinderPose7](../models/cylinderpose7.md)（默认） |
| 黑暗中、近红外光照明，透过玻璃底板从下方拍摄（暗箱 / Blackbox 类装置） | **近红外（暗箱）** — [PalmReaderPose8](../models/palmreader8.md) |

同一研究的所有视频请用同一个模型识别。

## 所有任务通用

- **每段视频一只小鼠**，整个录像过程中完整地在画面内。如果多个观察箱一起拍摄，先把每个观察箱裁成单独的视频。
- **固定相机**，装在三脚架或支架上。实验过程中不要变焦或移动。相机固定还可以让所有视频共用一次标定。
- **均匀、柔和的光照**，没有移动的阴影。避免亚克力反光。
- **让装置填满画面**。爪占的像素越多越好。
- **清晰的画面**：快门要足够快，能定格爪的运动。光线不足时请加光，不要让相机延长曝光。
- **帧率**：至少 25–30 fps；快速行为（抓挠、缩爪、步态）需要 60 fps 或更高。

## 文件格式 {#file-formats}

RodentLimb 通过 macOS（AVFoundation）读取视频：H.264 或 HEVC 编码的 MP4 和 MOV 可以直接使用，包括 iPhone 拍的视频。导入表格会检查每个文件，并标出 Mac 无法解码的文件，例如：

- **AVI、MKV** 等 macOS 打不开的封装格式；
- 没有 AV1 解码器的 Mac（M1 和 M2）上的 **AV1**，以及 VP8 / VP9。

请先把这类文件转换为 H.264 MP4，例如用 ffmpeg：

```bash
ffmpeg -i input.avi -c:v libx264 -crf 18 -pix_fmt yuv420p -an output.mp4
```

## 各任务 {#per-task}

| 任务 | 相机 | 时长 | 说明 |
|---|---|---|---|
| [悬尾实验](../assays/tail-suspension.md) | 从悬挂小鼠的正面（腹侧）或背面（背侧）拍摄，两只后爪都可见 | 从悬挂开始 6 分钟 | C57BL/6 等品系可用防爬尾套减少爬尾 |
| [圆筒实验](../assays/cylinder.md) | 透过透明底板从下方拍摄（最佳）；侧面也可以 | 5–10 分钟，或约 20 次站立 | 避免圆筒后面有镜子 |
| [步态分析](../assays/gait.md) | 从笔直走道的透明底板下方拍摄 | 多次通过 | ≥ 60 fps（120–240 fps 更好）；如需厘米，画面中放一次尺子 |
| [瘙痒](../assays/itch.md) | 透过透明底板从下方拍摄，每个观察箱一只小鼠 | 注射后 30–60 分钟 | ≥ 30 fps，60 fps 更好；设置注射时刻 |
| [自发痛行为](../assays/pain.md) | 从下方拍摄，注射爪可见 | 福尔马林 45–60 分钟，辣椒素 5–10 分钟 | ≥ 30 fps；设置注射爪和注射时刻 |
| [自我理毛](../assays/grooming.md) | 从下方拍摄，一只小鼠 | 短暂适应后 10 分钟；喷雾实验在喷雾后立即开始 | ≥ 30 fps |
| [癫痫发作评分](../assays/seizure.md) | 透过透明底板或圆筒从下方拍摄 | 从注射前到注射后 ≥ 30 分钟 | ≥ 30 fps；每个事件都要在视频上确认 |

如果视频在注射之前就开始，请在分析参数中设置**注射时刻**；潜伏期、分相和时间分箱都从这一刻算起。

::: tip 可见光模型是用圆筒实验视频训练的
CylinderPose7 从自下方拍摄的圆筒实验录像中学习。用于其他任务和视角时，请先在几段视频上检查关键点叠加，再给整个研究评分。如果爪的跟踪不好，最有效的办法是用你自己装置的标注帧改进模型。
:::
