# 怎样拍出好识别的视频

爪越大、越清晰、光线越均匀，模型识别得越好。在拍摄设置上多花几分钟，能省下之后大量的核对时间。

## 所有范式通用

- **每段视频一只小鼠**，整个录制过程中完整在画面内。
- **相机固定**在三脚架或支架上，录制中不要变焦或移动。相机固定时，一次标定可用于所有视频。
- **光线均匀柔和**，没有移动的阴影，避免亚克力反光。
- **让装置填满画面**。每只爪占的像素越多越好。
- **画面清晰**：快门速度足以冻结爪的运动。光线暗时应补光，而不是让相机延长曝光。
- **常见格式**：iPhone 拍摄的视频（HEVC 或 H.264，MOV 或 MP4）可直接使用。

## 悬尾实验

- 从**正面（腹侧）或背面（背侧）**拍摄悬挂的小鼠，保证两只后爪都可见。侧面无法判断后肢抱握。
- 从悬挂那一刻开始录制。标准测试 **6 分钟**，通常统计第 **2–6 分钟**的不动时间。
- 每个隔间、每段视频一只小鼠。对 C57BL/6 等易爬尾的品系，可在尾根套一小段管子（climb-stopper）减少爬尾。

## 圆筒实验

- 最佳方式是透过透明底面**仰视**拍摄，触壁的爪会出现在圆周边缘。
- 也可**侧视**拍摄，此时标定地面线即可。
- 小鼠用圆筒通常直径约 9–10 cm、高约 15 cm。录制 **5–10 分钟**，或约 20 次竖立。
- 圆筒后方的镜子方便人工评分，但会干扰模型。优先使用单一直接视角。

## 步态分析

- 透明步道的**仰视（腹侧）**拍摄。
- **高帧率**：支撑相和摆动相只有几十毫秒，请用 **60 fps 或更高**（120 或 240 fps 更好）。30 fps 时时间分辨率只有 33 毫秒，占空比会有偏差。
- 让小鼠多走几趟。只分析稳定的直线行走，趟数越多，步幅越多。
- 如需厘米单位，在画面中放一次标尺或已知距离的标记。
