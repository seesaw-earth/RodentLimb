# 导入视频

## 添加文件

把视频或文件夹拖进窗口，或选择 **文件 › 导入视频…**（⌘O）。文件夹会递归查找。要直接导入某个研究，在研究页面使用 **导入视频到此研究…**（⇧⌘I）。

导入之前，导入表格会读出每段视频的**时长、帧率和分辨率**，并试解码一帧：

- macOS 打不开的文件，或这台 Mac 无法解码的编码（例如 M1/M2 Mac 上的 AV1），标为**无法读取**，并说明如何转换为 H.264 MP4。见[拍摄视频](./recording.md#file-formats)。
- 已经导入过的文件会被识别出来，标为重复。

## 从文件名读出动物、时间点和试次

RodentLimb 从文件名和文件夹名填写**动物**、**时间点**和**试次**。如果命名有规律，可以设定规则，例如*用 `_` 分割；第 1 段是动物，第 2 段是时间点*。选中多行可以一起修改。

## 本次导入的选项

| 选项 | 作用 |
|---|---|
| **研究** | 把视频放入已有或新建的研究，或不放入研究 |
| **时间点、分组、备注** | 应用于本次导入的每段视频（盲态研究中分组保持隐藏） |
| **计划任务** | 视频纳入后为它生成的分析。没有任务的视频会被识别和检查，但在分配任务之前不会评分 |
| **姿态模型** | *可见光——默认（CylinderPose7 FP16）* 或 *近红外暗箱（PalmReaderPose8）*。见[模型与来源](../models/) |
| **视频文件** | *保留在原位置（推荐）* 或 *将视频复制到资料库*。复制时会显示所需空间和剩余空间 |

新导入的默认模型可以在 **设置 › 处理 › 姿态模型** 中修改。

## 视频保留在原处

默认情况下视频是**引用，而不是复制**：RodentLimb 保留读取它们的权限（安全范围书签），从不修改视频。为了识别被移动或替换的文件，它保存一个由文件大小、修改日期以及首尾各 1 MB 组成的指纹。

- 视频被移动后，用 **定位视频…** 指向新位置。
- 硬盘没有连接时，其中的视频在队列中显示为**离线**，接回后继续。
- 如果文件被另一个文件替换，RodentLimb 会提示并重新识别。

## 用另一个模型重新识别

要重新识别一段视频（例如换用另一个模型），在视频表格中右键点按它并选择 **重新识别…** 和所需模型，或在视频页面使用 **重新识别**。它的关键点会被替换，分析会重新计算。
