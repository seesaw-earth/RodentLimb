# 快速上手

下面完整走一遍分析流程。除视频处理时间外，只需几分钟。

## 1. 新建分析

在**首页**点“新建分析”，或直接点三个范式入口之一来预选范式。

1. 选择**范式**：悬尾、圆筒或步态。
2. 点**添加视频**，从**照片**或**文件**中选择。可一次添加多段，每段一只小鼠。
3. 核对**动物编号**。默认取文件名；点一下可修改，按回车跳到下一个。
4. 可选填写**组别**（如 *Vehicle*、*6-OHDA*）和备注。
5. 点**开始分析**。

::: tip 批量分析
可以一次添加整组动物。视频在后台队列中逐个处理，你可以继续做别的操作。
:::

## 2. 等待姿态识别

模型逐帧读取视频，进度显示在首页和记录页面上。请保持 App 在前台：切换到其他 App 时会暂停，回来后自动继续。

## 3. 标定（圆筒必需，步态可选）

- **圆筒实验**：把圆圈拖到圆筒边缘（仰视），或把横线拖到底面（侧视）。“根据追踪自动拟合”可给出初始位置。
- **步态**：可选，拖动标尺跨过已知距离并输入厘米数。不标定时，长度以体长为单位。
- **悬尾**无需标定。

如果相机没有移动过，选择“保存并用于该范式的所有视频”。见[标定](./calibration.md)。

## 4. 查看结果

每个结果有三栏：

- **概览**：关键数字、提示和一张主图。
- **回放**：叠加关键点的视频，以及指标背后的具体事件。
- **全部指标**：按类别分组的所有指标和详细图表。

见[结果与回放](./results.md)。

## 5. 调整与导出

- **参数**（底部栏）：阈值和窗口。拖动滑块时结果实时更新。“应用到该范式的所有记录”可保持整个研究参数一致。
- **导出**：汇总、事件或步幅表、逐帧姿态 CSV 和方法描述。见[数据、组间比较与导出](./data.md)。
