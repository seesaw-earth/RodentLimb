# Mac 快速上手

本页从新建任务开始，一直走到导出数据表。从 1.4 版起，一切都从**任务**开始：先选实验，再添加它的视频。每一步都链接到详细说明。

## 1. 安装并打开

从 [App Store](https://apps.apple.com/app/id6822935387) 安装 RodentLimb 并打开。在 **RodentLimb › Language · 语言**（侧栏底部和“设置”中也有）选择 English 或简体中文。

App 把工作内容保存在一个**资料库**文件夹中。默认资料库会自动创建；若要把项目放在外接硬盘上，用 **文件 › 打开资料库…** 选择文件夹。见[资料库与文件](../reference/files.md)。

## 2. 新建任务

点工具栏的 **新建任务**（⇧⌘N）。先选择范式（悬尾、圆筒、步态、瘙痒、自发痛、自我理毛或癫痫发作评分），再填写任务名称、组别（例如 *WT* 和 *KO*）、时间点、备注以及是否盲法。侧栏列出每个任务及其组别；选中某个组别时只显示该组的会话。见[研究、分组与盲法](./data.md)。

## 3. 添加视频

在任务页点 **添加视频…**（⌘O），或把视频、整个文件夹拖进窗口。表格会读出每段视频的时长、帧率和分辨率，并提示 Mac 无法解码的文件。

- 检查从文件名和文件夹名读出的**动物**、**组别**、**时间点**和**试次**，或设置命名规则。任务中已有的动物保持原组别。
- 选择**姿态模型**：室内光视频用*可见光*（默认），暗箱中从下方拍摄的视频用*近红外暗箱*。

每段视频添加后立即成为任务中的一个会话。见[导入视频](./import.md)。

## 4. 让队列运行

识别会自动开始。**处理队列**页显示正在识别的视频及其关键点、进度、帧率和整个队列的剩余时间。可以暂停（⌘.）、调整顺序或取消视频，也可以关闭窗口，或退出后再继续。见[处理队列](./processing.md)。

## 5. 检查识别质量

视频识别完成后，按任务的标准检查（默认：≥ 90 % 的帧中追踪到小鼠、没有超过 10 秒的缺口、帧率 ≥ 25 fps）。通过的视频自动纳入；其余的出现在**待复核**中：查看识别结果，按 **I** 纳入，或按 **E** 并写明原因排除。见[质量控制与纳入](./qc.md)。

## 6. 评分与标定

任务页有三个标签：**会话**（每段视频及其状态，如“识别中 45%”“待复核”“需要标定”）、**结果**（组间比较、完整性、排除记录）和**设计**。打开一个会话查看结果。圆筒实验需标出圆筒边缘（底视）或地面线（侧视）；步态可选标一把厘米标尺。见[标定](./calibration.md)和[任务、参数与预设](./parameters.md)。

## 7. 复核事件

会话的 **回放** 标签在视频上画出关键点，并列出每个检测到的事件：每次触壁、抓挠回合、舔爪或发作。用 ↑/↓ 逐个查看，用数字键修改标签，指标随之更新。见[结果与复核](./results.md)。

## 8. 导出

按 ⌘E。在任务页导出的是该任务（或你选中的会话）。RodentLimb 写出一个文件夹，包含汇总表、行为片段、时间分箱、QC 表、方法学文字和数据字典。见[导出](./export.md)。

::: tip 正式实验之前
先识别几段预实验视频，检查叠加效果，人工评分几段并调整参数，直到自动结果与人工一致。然后固定设置，应用到任务中的所有会话。见[验证与局限](../principles/validation.md)。
:::
