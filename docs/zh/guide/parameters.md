# 参数

姿态识别只运行一次，之后的所有计算都基于保存下来的关键点，因此下面每个参数都可以随时修改。拖动滑块时结果实时更新，表单顶部的关键数字会立即反映变化。

## 保持研究内参数一致

- “应用到该范式的所有记录…”会把当前参数复制到同一范式的每条记录。圆筒实验的损伤侧按动物分别保留。
- “恢复默认值”回到下文的默认值。
- 新记录会沿用同一范式上一条记录的参数。
- 实际使用的数值会写入每条记录导出的**方法描述**。

## 以体长为单位

速度和距离以**体长（BL）**表示，即整段视频中鼻尖到尾根距离的中位数。因此阈值可在不同相机和缩放之间通用。成年小鼠 1 BL 约为 8–9 cm。

## 姿态预处理（高级）

所有范式共用，见[姿态模型与预处理](../principles/pose.md)。

| 参数 | 默认值 | 含义 |
|---|---|---|
| 关键点置信度 | 0.30 | 低于该置信度的关键点视为缺失 |
| 填补缺口上限 | 0.25 秒 | 更短的缺口线性插值 |
| 位置平滑 | 0.10 秒（步态 0.03 秒） | 先 3 点中值滤波，再居中滑动平均 |

## App 设置

在“设置”中：

- **检测置信度**（默认 0.25）：接受小鼠检测结果的最低分数。经常漏检时可调低，对之后的识别生效。
- **同时生成骨架视频**：输出画好骨架的 MP4，仅分享时需要，会使识别变慢。
