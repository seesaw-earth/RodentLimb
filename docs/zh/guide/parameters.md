# 任务、参数与预设

一个**分析**是用一个任务给一段视频评分。一段视频可以有多个分析，例如同一段录像的*瘙痒*和*自我理毛*。

## 分配任务

- 导入时勾选**计划任务**：每段视频纳入后立即生成这些分析。
- 之后也可以在表格中选择视频，选择 **分配任务…**。
- 分析在后台计算，可同时计算多个。

## 修改参数

打开一个分析，参数在右侧的检查器中。结果立即重新计算，因为模型不需要再运行，只重复预处理和评分。

**应用到…** 把参数复制到研究（或所选内容）中同一任务的其他分析。每段视频保留自己的**注射时刻**和**注射爪**，因为它们因视频而异。同一研究的所有动物请使用相同的参数并报告：每个数值都会写入导出的方法学文字。

## 关键点预处理（所有任务）

| 参数 | 默认 | 作用 |
|---|---|---|
| 关键点置信度 | 0.30 | 低于此值的点视为缺失 |
| 填补缺口上限 | 0.25 秒 | 较短的缺口被填补；较长的保持缺失，不计入任何指标 |
| 填补方法 | 线性插值 | 另有：三次保形插值、身体相对坐标（爪随身体移动）、Kalman 平滑 |
| 剔除不合理跳点 | 关 | 把远离相邻帧所示位置的点视为缺失 |
| 跳点阈值 | 0.5 体长 | 与 ±0.1 秒内中位位置的距离 |
| 位置平滑 | 0.10 秒（步态 0.03 秒） | 3 点中值滤波之后的居中滑动平均 |

详见[姿态模型与预处理](../principles/pose.md)。

## 来自已发表实验方案的预设

检查器顶部的**实验方案**提供预设，设置已发表方案所规定的数值：评分时间窗、分相、分箱、回合规则、步幅筛选或关键点置信度。拍摄视角、损伤侧、注射时刻、注射爪和标定保持不变。默认值与 iPhone 版相同，因此除非选择预设，已有结果不会改变。

| 任务 | 预设 | 主要设置 | 来源 |
|---|---|---|---|
| 悬尾实验 | **6 分钟中的后 4 分钟**（默认） | 评分 2:00–6:00 | Can 等，2012 |
| | 完整 6 分钟 | 0:00–6:00 | Steru 等，1985 |
| 自发痛行为 | **福尔马林 0–10 / 10–60 分钟**（默认） | 5 分钟分箱 | Mogil 等，1999 |
| | 福尔马林 0–5 / 20–30 分钟 | 小鼠舔爪的两个峰 | Hunskaar 等，1985；Hunskaar & Hole，1987 |
| | 福尔马林 0–5 / 20–40 分钟 | 小鼠实验方案 | Nian 等，2014 |
| 步态分析 | **App 默认** | ≥ 1 体长/秒，转向 ≤ 30°/秒，去掉每次行走的首尾步幅 | RodentLimb 模拟 |
| | 旷场步幅（JAX） | 约 0.5 体长/秒（尾根 ≥ 5 cm/秒），±20°/秒，置信度 > 0.3 | Sheppard 等，2022 |
| 圆筒实验 | 前 20 次触壁 | 记满 20 次触壁后停止计分 | Schallert 等，2000 |
| | 5 分钟实验 | 前 5 分钟内的全部触壁 | Bentea 等，2025（protocols.io） |
| | **整段视频**（默认） | 不限 | |
| 瘙痒 | **急性致痒剂：30 分钟**（默认） | 5 分钟分箱；相隔 < 2 秒的回合组成抓挠串 | Park 等，2019；Kobayashi 等，2021；Yu 等，2022 |
| | 自发 / 慢性瘙痒：60 分钟 | 10 分钟分箱 | 慢性瘙痒模型的常用做法 |
| 自我理毛 | **10 分钟实验**（默认） | 停顿 > 5 秒结束一个回合 | Estanislau，2012 |
| | Kalueff：5 分钟，6 秒回合 | 短于 6 秒的停顿算回合内的中断 | Kalueff & Tuohimaa，2004；Kalueff 等，2007 |
| | 适应 10 分钟后（10–20 分钟） | 自闭症模型实验方案 | McFarlane 等，2008；Silverman 等，2010 |
| 癫痫发作评分 | **PTZ：30 分钟**（默认） | 修订版 Racine 量表（1–7 级） | Van Erum 等，2019 |
| | 海人酸 / 毛果芸香碱：2 小时 | 改良 Racine 量表（1–5 级），10 分钟分箱 | Racine，1972；Sharma 等，2018 |
| 所有任务 | 关键点：置信度 0.6 + 去除跳点 | 更严格，缺口更多 | DeepLabCut 的默认阈值（Mathis 等，2018） |

**默认值是怎么定的。** 时间窗、分相和分箱属于实验设计，所以预设直接采用文献值，也便于与已发表数据比较。以体长为单位的速度和距离阈值取决于相机和动物大小；文献中的 cm/秒只能近似换算，所以 App 的默认值保持不变，已发表的设置作为预设提供。置信度 0.6 会去掉更多错误位置，但缺口更多；视频较短或遮挡较多时，通常 0.3 更好。同一研究的所有动物请使用同一个预设。

各任务特有的参数见[实验任务](../assays/)中的对应页面。
