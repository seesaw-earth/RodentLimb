# RodentLimb 是什么

RodentLimb 是一款用于**小鼠行为视频肢体级分析**的 iPhone App。姿态模型在每一帧中找出 7 个身体部位，App 据此完成三种常用的运动与行为实验分析：

- **[悬尾实验](../assays/tail-suspension.md)**：不动时间、潜伏期、不动次数、爬尾和后肢抱握。
- **[圆筒实验](../assays/cylinder.md)**：竖立时前爪的使用（左、右、双爪）及其不对称性。
- **[步态分析](../assays/gait.md)**：每只爪的支撑相与摆动相、步幅、占空比、支撑面宽度、肢间协调和步态模式。

它与 **RodentFlow**（质心追踪与统计）和 **RodentPose**（旷场、迷宫等范式的全身姿态分析）同属一个系列。

## 七个关键点

| 关键点 | App 中的颜色 |
|---|---|
| 左前爪（LF） | <span class="paw lf"></span>蓝 |
| 右前爪（RF） | <span class="paw rf"></span>红 |
| 左后爪（LH） | <span class="paw lh"></span>绿 |
| 右后爪（RH） | <span class="paw rh"></span>紫 |
| 尾根 | <span class="paw tb"></span>粉 |
| 鼻尖 | <span class="paw nose"></span>琥珀色 |
| 嘴 | <span class="paw mouth"></span>浅蓝 |

左右指的是**动物自身**的左右。如果你的相机画面是镜像的，请在[参数](./parameters.md)中打开“交换左右标签”。

## 特点

- **只跑一次，随意重算。** 每段视频只运行一次姿态识别。所有阈值、分析窗口和标定都可以事后修改，结果立即更新。
- **以体长为单位。** 距离和速度按动物自身的鼻尖—尾根长度换算，换相机或缩放后设置依然适用。厘米标尺是可选的。
- **每个数字都可核对。** 回放器在视频上叠加关键点；圆筒实验的每一次触壁都可以回放并修改标签。
- **导出即用。** CSV 文件和包含实际参数及参考文献的方法描述，始终为英文。
- **隐私。** 无账号、不联网、无统计分析，见[隐私政策](../privacy.md)。

## 系统要求

iOS 17 或更高版本的 iPhone 或 iPad。界面语言：英文和简体中文（在“设置”中切换）。

::: tip 科研使用
自动评分用于辅助，而不能取代对视频的盲法复核。下结论前，请先用人工评分验证你的实验条件，见[验证](../principles/validation.md)。
:::
