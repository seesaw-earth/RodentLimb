# RodentLimb 是什么？

RodentLimb 在肢体层面测量小鼠行为。姿态模型在视频的每一帧中找出四只爪、尾根、鼻尖和嘴；App 再清洗这些轨迹，并据此对标准实验评分。全部在你的 Mac（或 iPhone、iPad）上运行，不需要账号，也不需要联网。

## 它做什么

1. **识别关键点**：用通过 Core ML 在本机运行的姿态模型逐帧识别。按录像的光照选择模型：室内光用 [CylinderPose7](../models/cylinderpose7.md)，黑暗中从下方拍摄的近红外视频用 [PalmReaderPose8](../models/palmreader8.md)。
2. **检查识别质量**：按你为研究设定的纳入标准检查每段视频，并记录视频被排除的原因。
3. **完成七项实验的评分**：悬尾、圆筒、步态、瘙痒（抓挠）、自发痛、自我理毛和癫痫，都来自同一组关键点。每项实验报告指标、背后的事件和时间进程。
4. **复核**：每个检测到的事件都可以在视频上回放并修改标签；指标随之更新，修改次数写入导出。
5. **组织研究**：因素和分组、时间点、动物、随机分配和盲法，组间汇总以动物为单位。
6. **导出**：可用于 R、Python、SPSS 或 Prism 的长格式表格，行为片段表，带参数和参考文献的方法学段落，以及 BORIS、DeepEthogram 和基于 DeepLabCut 的工具所用的文件。

## 适合谁

已经在这些实验中拍摄小鼠、希望得到可重复的关键点指标又不想写分析代码的实验室。模型每段视频只运行一次；阈值、时间窗和标定之后都可以修改，结果立即更新，因此可以按你自己的人工评分来调整设置。

## Mac 版

RodentLimb for Mac 为大量长视频而设计：把一个文件夹拖进窗口，让队列通宵运行，第二天早上复核并导出。识别结果逐帧保存，暂停、崩溃、笔记本合盖或硬盘拔出都不会丢失工作。见 [Mac 快速上手](./getting-started.md)。

系统要求：macOS 14 Sonoma 或更新版本。支持 Apple 芯片和 Intel Mac，Apple 芯片快得多。界面：英文和简体中文（在 **RodentLimb › Language · 语言** 中切换）。导出文件始终为英文。

## iPhone 与 iPad

iPhone 和 iPad 版与 Mac 版共用分析代码和资料库格式。资料库可以从 iPhone 拷贝到 Mac 上打开。见 [iPhone 与 iPad](./iphone.md)。

## 它不做什么

- 不诊断疾病，不是兽医或临床工具。
- 不能代替人工抽查一部分视频。默认阈值来自模拟数据和已发表的实验方案；正式研究前请按自己的人工评分设定。见[验证与局限](../principles/validation.md)。
- 每段视频只分析一只小鼠。
- 不录制视频，也不渲染画有骨架的视频。
