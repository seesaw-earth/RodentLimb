# 质量控制与纳入

每段视频在识别之后、评分之前检查一次。检查回答这些问题：是否找到了小鼠，哪些关键点被识别，缺失部分有多少能通过短缺口填补，不能填补的片段有多长，有没有不合理的跳点，视频本身是否合适。

## 预先设定的标准

标准属于研究，应在评分之前设定，这也是 ARRIVE 2.0（第 3 项）的要求：纳入和排除标准预先说明，每次排除都报告原因。

| 标准 | 默认 |
|---|---|
| 短缺口填补后小鼠（鼻尖和尾根）可用 | ≥ 90% 的帧为通过；低于 70% 为不通过 |
| 找不到小鼠的最长片段 | ≤ 10 秒 |
| 帧率 | ≥ 25 fps |
| 关键点不合理跳点的帧 | ≤ 2% |

在研究页面的 **纳入标准（QC）** 卡片中修改。不属于任何研究的视频使用默认值。

## 结论

- **QC 通过**：满足所有标准。视频**自动纳入**。
- **QC 警告**：介于通过和不通过之间。需要你决定。
- **QC 未通过**：低于不通过的标准。需要你决定，通常予以排除。

## 复核视频

侧栏中的**待复核**（⌘3）列出等待决定的视频。

- 在 QC 播放器中查看识别结果：它显示原始关键点，并可以在丢失小鼠的片段之间跳转。
- **I** 纳入视频；**E** 排除并要求选择原因；**↓ / ↑** 切换到下一段或上一段视频。**全部纳入已识别的** 一次纳入列表中所有已识别的视频。
- 决定立即保存。

每个决定及其原因都写入导出中的 `qc_videos.csv`，同时写入覆盖率、最长丢失片段和姿态模型。方法学文字会说明这些标准。

## 每个结果中的覆盖率

每个分析还会报告它所用帧的**姿态覆盖率**（或爪的可见率）。覆盖率低时，结果中会有提示；请谨慎解读这些指标。
