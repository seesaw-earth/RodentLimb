# 结果与复核

在表格中双击、从研究页面，或从处理队列页的 **打开分析** 打开一个分析。结果有三个标签页（⌥⌘1–3）。

## 概览

该任务最重要的两到四个数字、提示（例如姿态覆盖率低、标定沿用自另一段视频、帧率对该任务过低），以及一张图：逐分钟不动曲线、抓挠时间进程、落足模式等。

## 回放

画有关键点的视频，下方是用彩色块表示检测到的事件的时间轴，右侧是事件列表。

| 操作 | 按键 |
|---|---|
| 播放 / 暂停 | 空格（或 K） |
| 上一帧 / 下一帧 | ← / →（或 , / .） |
| 后退 / 前进 1 秒 | ⇧← / ⇧→ |
| 后退 5 秒 / 播放 | J / L |
| 上一个 / 下一个事件（视频跟随） | ↑ / ↓ |
| 修改所选事件的标签 | 1–9 对应该任务的类别，0 = 忽略 |
| 撤销修改 | ⌘Z |

修改标签后指标立即更新。修改随分析保存，参数改变时保留，在结果中计数（*人工修改事件*），并写入方法学文字和行为片段表（每个事件的自动标签、复核后标签和 *edited* 标记）。

可修改的内容取决于任务：圆筒实验的每次触壁（左、右、双爪、忽略），每个抓挠回合或擦脸片段，每次舔爪或缩爪事件，每个理毛回合及其部位，以及每个癫痫事件及其分级。悬尾和步态通过图表和视频复核。

## 全部指标

该任务的所有指标按组列出，附详细图表：步态的足印图和相位盘，瘙痒和疼痛的时间分箱，理毛和癫痫的行为谱。可以复制到剪贴板。

## 重新运行

参数、标定或标签改变时，分析会自动重新计算。**重新分析** 用当前参数重新计算所选分析，例如在 App 更新之后。
