# 结果与回放

从首页或“数据”页打开一条记录。姿态识别进行中时显示进度；完成后页面有三栏和一个底部栏。

## 概览

- **关键数字**：该范式最重要的两到四个数值，例如悬尾实验的不动时间和比例。
- **提示**：警告和建议，如姿态覆盖率低、触壁或步幅太少、帧率偏低。点一下可展开全部。
- **一张主图**：运动曲线（悬尾）、前爪使用（圆筒）或足落模式（步态）。悬尾实验中，点图表可跳到“回放”中对应的时刻。

## 回放

回放器在原始视频上叠加关键点。

- **点视频**播放或暂停。
- **拖动进度条**快速定位，画面和关键点同步移动。
- **在视频上左右滑动**可逐帧移动（每 6 个点一帧）。
- **◀︎ ▶︎ 逐帧按钮**每次移动一帧。
- **倍速菜单**（0.25×–4×）和“显示关键点”开关。
- **视频上的状态标签**：*不动 / 挣扎 / 爬尾*（悬尾）、*左爪触壁 / 右爪触壁*（圆筒）、*支撑 LF RH…*（步态）。

回放器下方：

- **圆筒**：触壁列表。点一行即播放该次触壁；用标签按钮改为*左爪、右爪、双爪*或*忽略*。修改参数或重新分析时，修改都会保留。
- **步态**：足落模式图跟随视频移动。
- **悬尾**：运动曲线，点击可跳转。
