# Keyboard shortcuts

| Where | Shortcut |
|---|---|
| Everywhere | ⌘O import videos · ⇧⌘N new study · ⌥⌘O open library · ⌘E export · ⌘R start tracking · ⌘. pause · ⌘, settings · ⌘0 main window · ⌥⌘⌫ Recently Deleted |
| Sidebar | ⌘1 Overview · ⌘2 Processing · ⌘3 Needs Review · ⌘4 All Videos. Show or hide the sidebar and the inspector from the **View** menu |
| Processing queue | ⌥⌘↑ move to front · ⌥⌘↓ move to back |
| Needs Review | I include · E exclude (choose a reason) · ↑ / ↓ previous / next video |
| Result | ⌥⌘1 Summary · ⌥⌘2 Review · ⌥⌘3 All measures · ⇧⌘E export this analysis · ⌘Z undo a relabel |
| Event list | ↑ / ↓ previous / next event (the video follows) · 1–9 relabel · 0 ignore · Space play / pause |
| Player | Space play / pause · ← / → frame by frame · ⇧← / ⇧→ ±1 s · J back 5 s · K pause · L play · , / . frame by frame |
| Study page | ⇧⌘I import videos into this study · ⇧⌘D edit design |
