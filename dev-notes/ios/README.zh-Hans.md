# RodentLimb（iPhone / iPad）1.4.2

端侧小鼠肢体姿态分析：**步态**、**圆筒**、**悬尾**，以及**瘙痒（抓挠）**、**自发痛（福尔马林/辣椒素）**、**自我理毛**、**癫痫发作（PTZ/海人酸）**评分。全部在本机运行，数据不离开设备。与 RodentPose、RodentFlow 同系列；Mac 版见 RodentLimb for Mac，资料库格式相同，可互相拷贝。

## 1.4 更新：先建任务，再处理视频

- **任务优先**（参照 RodentFlow）：一个**任务**就是用一种范式完成的一次实验，例如“步态——SNI 第 2 批”。先新建任务，再在任务里添加视频；数据和分组始终沿着 **任务 → 组 → 动物 → 实验（时间点 · 试次 · 日期）** 组织。
- **两个标签页加设置**：任务 · 处理 · 设置。原来的首页、研究、数据页合并进“任务”。
- **新的姿态模型**：移除 38 MB 的 CylinderMousePoseV2，改为两个可选模型（见下文）。
- **去掉装饰性图标和表情符号**：状态用简短的彩色文字或小圆点表示，范式用文字标签；只保留标签栏、播放控制和“+”按钮。
- **数据不丢失**：最近删除（30 天，可撤销）、每日备份、即时保存（见下文）。
- **组结果图**：每只动物一个点，组均值 ± 标准误，标出每组 n；分箱指标有按组的时间进程。

## 使用流程

1. **新建任务**（任务 › +）。先选范式（按用途分组，每项一句说明）：
   - 运动功能：步态分析 · 圆筒实验
   - 疼痛与瘙痒：瘙痒（抓挠）· 自发痛
   - 情绪与刻板行为：悬尾实验 · 自我理毛
   - 癫痫：癫痫发作评分

   再填写名称（默认“范式 + 日期”）、分组（默认两个空行，提示 Control / Treatment，可留空）、可选的时间点和备注。
2. **添加视频**（任务页的主按钮）。从文件、文件夹或照片选择，iPad 上也可直接拖入。每段视频一行：
   - **动物编号**从文件名读取（已登记的编号优先）；照片中的视频默认编号为 M1、M2……（取任务中尚未使用的号码），可修改；
   - **分组**从任务的分组中选择；文件名或文件夹名含有组名时自动填好；任务中已有的动物保持原分组；
   - **时间点**和**试次**（文件名中的 T2、trial2 会被识别）；
   - **姿态模型**每批选一次；已在资料库中的视频（按指纹识别）会被标出并跳过。

   点“添加”后，新动物及其分组一次性加入任务，每段视频立即成为任务中的一个**实验**并逐个写入磁盘，然后排队识别。文件夹请用“从文件”选择；iPad 上可拖入视频文件。
3. **处理**：后台逐个识别（每段视频只跑一次所选模型）。进度显示在实验行和“处理”页；离开 App 会暂停，回来后从中断的那一帧继续；崩溃也不会丢失已保存的数据。全部完成后“处理”页给出下一步（待审核、未归入任务的视频）。
4. **质量检查（QC）**：通过的视频自动纳入；其余进入“待审核”（任务页会显示数量），检查视频后选择纳入，或填写原因后排除。被排除的实验仍显示在任务中并有标记，但不计入组结果。
5. **标定**：只有圆筒（圆筒边缘或地面线）和步态（可选厘米标尺）需要；可“用于本任务的所有实验”。
6. **结果**：
   - 实验页：概览 · 回放（视频与事件）· 全部指标；参数在底部的“参数”中（顶部可选“实验方案”预设，并可“应用到本任务的其他实验”）。
   - **任务页**是中心：标题（名称、范式、各状态计数）、主按钮“添加视频”，以及 **实验 | 结果 | 设计** 三栏。实验按组 → 动物排列；结果为组间比较和时间进程；设计包括分组、动物（可随机分组）、时间点、纳入标准、参数、标定和盲法。
7. **导出**（任务页右上角）：汇总（每个实验一行，长格式）、QC 表（含所用模型、纳入决定与原因）、事件、时间分箱、方法说明（写明实际使用的模型）与研究设计、README、manifest。导出文件始终为英文；盲法期间不含动物编号、分组和文件名。

**移到任务 / 从任务中移除**（均可撤销）：
- 一段视频只属于一个研究。移到另一个任务的研究时，它在原研究其他范式中的实验会作为一项移到“最近删除”（不会多出一个任务）；在同一研究内换任务时，原任务的实验移到“最近删除”。视频原来的分组（原任务未设盲时的动物分组，或未归入任务视频的文字分组）会成为目标任务中该动物的分组（单因素、未设盲、动物尚无分组时）。
- “从任务中移除，保留视频”：该实验移到“最近删除”；视频若没有其他实验，就离开该研究，动物编号和分组以文字保留，出现在“未归入任务”。
- 盲法期间不能把视频移出或移到其他任务。
- 删除任务：若研究只有这一个任务，删除整个研究（可选择保留视频）；若是含多个范式的旧研究，只移除该范式的实验。两种情况删除后都可立即“撤销”。
- 视频离开所有任务时不会重新计算 QC，纳入决定保持不变；加入某个研究时按该研究的标准重新检查，但只有识别后的第一次 QC 会自动纳入。

旧数据（iPhone 1.0–1.3）原样打开（资料库在后台读取，期间显示“正在打开资料库…”）：含多个范式的旧研究显示为每个范式一个任务（“研究名 · 范式”）；不属于任何研究的视频在“任务 › 未归入任务”中，可“移到任务…”；1.3 中“计划任务”但尚未分配的视频会自动出现在对应任务中；为未选范式的旧研究选择范式后，其所有视频都会得到该范式的实验。

## 姿态模型

| 模型 | 用途 | 关键点 |
|---|---|---|
| **CylinderPose7_FP16_640**（默认） | 普通室内光（可见光）、仰视；CylinderMousePoseV2 的半精度版本，同一网络，19 MB | 7：四爪、尾根、鼻尖、嘴 |
| **PalmReaderPose8_640_W8A16** | 暗箱中近红外仰视拍摄（Blackbox“Palmreader”类装置；Zenodo 16321240） | 8：映射为四爪、尾根、鼻尖（snout）；无嘴，舔爪和面部理毛改用鼻尖 |

- 添加视频时选择模型，默认值可在“设置 › 姿态模型”中修改；同一任务的视频请使用同一个模型。
- 每段视频记录所用模型（`Recordings/<id>/source.json`，与 Mac 版格式相同；`pose.bin` 中也有）。没有记录的旧视频是用 CylinderMousePoseV2 识别的，结果保留；重新识别时使用 FP16 模型。
- 视频页或实验页的“更多 › 重新识别”可以换用另一个模型。
- 导出和方法说明写明每段视频实际使用的模型。

安装或更新模型（Mac 上，在 RodentLimb-iOS 文件夹中）：

```bash
python3 Tools/install_model.py --fp16 ~/Downloads/CylinderPose7_FP16_640.mlpackage.zip
python3 Tools/install_model.py --nir  ~/Downloads/PalmReaderPose8_640_W8A16.mlpackage.zip
open RodentLimb.xcodeproj
```

工程使用同步文件夹（Xcode 16+），模型和源文件会自动加入。选择 Signing Team 后，在 iOS 17 以上的 iPhone 或 iPad 上运行。可选的抓挠模型：`python3 Tools/install_scratch_model.py ~/Downloads/compact_scratch_model.json`（`--remove` 恢复为规则检测）。

## 数据安全

- **随时保存**：修改先写入内存、约 0.4 秒内写入磁盘（后台串行队列，连续修改时最迟约 2 秒）；纳入/排除决定、删除、每段添加的视频和任务修改立即写盘；App 切到后台时全部写完。文本框（含排除原因）在回车、失去焦点和离开页面时保存。
- **中断的导入**：若添加视频时 App 崩溃，留下的未完成视频文件夹会在下次启动时移到“最近删除”，可恢复为待识别的视频；临时副本会自动清理。
- **最近删除**：删除任务、视频或实验时，文件夹移到 `RodentLimb/Recently Deleted/`，保留 30 天；删除或移动后底部出现“撤销”，也可在“设置 › 最近删除”中恢复或立即删除。恢复删除的任务时，视频的纳入决定和排除原因一并恢复。
- **备份**：每天一次，以及删除和批量修改前，自动备份所有任务、视频信息、纳入决定和实验参数（`RodentLimb/Backups/`，保留 14 个每日备份和 10 个其他备份）。在“设置 › 备份”中恢复；恢复不会删除任何内容，也不改动识别结果，恢复前会先备份当前状态。
- 所有文件都在“文件 › 我的 iPhone › RodentLimb”中，与 Mac 版资料库格式相同。

## 指标

| 范式 | 指标 |
|---|---|
| 步态 | 速度及变异系数、前后肢步幅、步频、支撑相、摆动相、占空比、支撑面宽度、足印位置、肢间相位及一致性 R、规律性指数、速度匹配值、左右不对称、步态模式 |
| 圆筒 | 左、右、双爪次数；设置损伤侧后有对侧使用率和不对称指数；竖立次数；每个事件可复核并改标签 |
| 悬尾 | 不动时间及比例（默认第 2–6 分钟）、潜伏期、不动次数与时长、逐分钟曲线、爬尾、后肢抱握估计评分 |
| 瘙痒 | 抓挠次数、时间、潜伏期、抓挠串、左右后爪；面颊模型另计擦拭 |
| 自发痛 | I 相 / II 相舔咬时间、次数、潜伏期、甩爪、舔对侧爪 |
| 自我理毛 | 时间、次数、潜伏期、各部位时间、中断比例、非头尾顺序转换比例 |
| 癫痫 | 最高分级、各级潜伏期、抽动/阵挛/惊厥次数、发作时长 |

阈值以体长（鼻尖到尾根距离的中位数）为单位。实验方案预设（悬尾后 4 分钟、福尔马林 Mogil 1999 / Hunskaar 1987 / Nian 2014、步态 JAX Sheppard 2022、圆筒前 20 次 / 5 分钟、瘙痒 30 / 60 分钟、理毛 Kalueff、癫痫 PTZ / 海人酸、关键点置信度 0.3 / 0.6）与 Mac 版相同。每个定义和参考文献见“设置 › 方法与参考文献”和 `Docs/behavior_scoring_conventions.md`。

## 局限

- 行为范式尚未与真实视频的人工评分做系统对照；默认参数只是起点，每个事件都可复核。抓挠约 20 Hz，请尽量用 ≥ 60 fps 录制。
- 可见光模型主要用圆筒视频训练；悬尾和步态视角不同时关键点可能不够准确，结果会显示姿态覆盖率并在覆盖率低时提示。
- 抱握评分是自动估计，请目视确认。步态指标受速度影响，请在相近速度下比较或把速度作为协变量。
- 组结果为描述性统计（以动物为实验单位）；推断检验请使用导出的长格式 CSV。
